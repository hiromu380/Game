## 2026-09-28 フェーズ2b メタ進行の導入と再調整

### 見つかった不具合（sim の修正）

- 再起動装置どうしが互いの発動回数をリセットし合い、「1回だけ」が破れていた。
  周りのプレス機・ドラム缶ごと tick 上限まで回り続け、スコアが 10^118 まで膨らんでいた
  → 再起動装置は他の再起動装置をリセットしないよう修正（CLAUDE.md のパーツ表にも明記）

### 変更内容

| 項目               | 前                                 | 後                                  | 理由                                                                             |
| ------------------ | ---------------------------------- | ----------------------------------- | -------------------------------------------------------------------------------- |
| シフト4〜9のノルマ | 60 / 140 / 300 / 700 / 1600 / 3500 | 80 / 250 / 600 / 2000 / 4000 / 8000 | 初期解放パーツ（品揃えが絞られて強い）では探索ボットがノルマの数百倍を出していた |

### 結果（seeds 1〜200、探索ボットは 1〜100）

| 状態                                             | random | greedy | search |
| ------------------------------------------------ | ------ | ------ | ------ |
| 初期解放のみ・7×7（初プレイ相当。検証の既定）    | 0%     | 69%    | 94%    |
| 全解放・9×9（やり込み相当、search は 60 シード） | -      | 29%    | 85%    |

### 判断（ユーザー確認済み）

- 解放でパーツの種類が増えると、ショップの品揃えが薄まり難しくなる。
  「解放は多様性であって強化ではない」として、**やり込むほど難しい**設計のままとする
- 探索ボットの失敗は主に「床の補修工事」の夜（初期解放で 95%）。ノルマではなく配置の崩れが原因

### ツール側の修正（調整の途中で見つかったもの）

- 再起動装置どうしがリセットし合う配置で信号が指数的に増え、メモリを使い切るシードがあった（seed 34）。
  → sim に「同時に存在できる信号数の上限」（`sim.maxLiveSignals = 1000`）を追加して打ち切るようにした
- ボットが「今夜の工事予告」を無視していたため、工事の夜に盤面が崩壊していた。予告マスを避けるよう修正
- 探索ボットに「全部手持ちに戻して組み直す」案を追加（人間は自由に組み替えるため）

### 目標に届いていない点と所見

- **貪欲ボット 31%（目標 50〜70%）**: 失敗 208 件のうち 75 件は「前のシフトと同じスコアのまま」脱落しており、
  組み替えができない貪欲ボット自体の限界。101 件はボスの夜で脱落（特に床の補修工事 62%）。
  これ以上ゲームを易しくすると探索ボットの後半がノルマの数百倍になるため、今回はここで止めた。
  → 「組み替えできる中級ボット」を作って目標を測り直すのが良い（フェーズ2bで検討）
- **ほぼ使われないパーツ**: ポンコツロボ（購入率 5%）・反射板（5%）・合流炉（7%）・回転台（9%）。
  いずれもタイミングや経路の工夫が要るパーツで、ボットでは価値を評価しきれていない可能性が高い。
  人が遊んで確認し、必要なら挙動を見直す（例: 合流炉を「合算 × 合流本数」にする）
- **よく使われるパーツ**: ギア・プレス機・散布機・連鎖メーター（探索ボットの購入率 44〜85%）。
- **後半の爆発**: 探索ボットの最終シフトはノルマの中央値 382 倍、最大で数十億倍。演出（桁の表記）で吸収する前提
