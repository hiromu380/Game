## 2026-10-08 金色パーツ（SIM_VERSION 8・数値は仮: 3つで合体・×3）

ツールの追加: ボットが組み立て後に「見込みが増えるときだけ」合体・手持ちの金色パーツを置く（`packages/bots/src/golden.ts`）。
`pnpm balance --golden off` で使わないボットと比べられる。100 シード・初期解放

| ボット | クリア率（金色なし → あり） | 1ランあたりの合体 |
| ------ | --------------------------- | ----------------- |
| greedy | 35% → 34%                   | 0.04              |
| mid    | 28% → 28%                   | 0.05              |

- ボットは合体のために並べ方を変えないので、ほとんど合体しない（たまたま3つつながったときだけ）。難しさへの影響は測れない
- 人は合体を狙って並べる（同じパーツを3つ買って2マス分を手放す代わりに ×3）。これは下限の目安で、強すぎるかは遊んだ記録で判断する
- → **数値は変えない**（3つで合体・×3・スイッチと共鳴コイルは対象外）。強すぎたら倍率を ×2 に、弱ければ合体の数を2つにするのが候補

## 2026-10-08 計測不能の閾値（延長戦の到達点の計測。表示だけで SIM_VERSION は変えない）

ツールの追加: `pnpm --filter @chain-factory/balance overtime --seeds 20 --bots mid --max-days 15`
（通常ランをクリアしたら延長戦に入り、脱落まで続ける。全パーツ解放・工場拡張も最大。ボットは金色パーツの合体をしない）

## 2026-09-28 フェーズ4d 慎重なプレイヤーでの検証・デイリーの検証（数値は変更していない。調整案のみ）

ツールの追加: `pnpm balance --mode daily`（デイリーと同じ条件: 3シフト・全パーツ・7×7・今日の特殊ルール）

### 通常ラン（`--eval worst --samples 5`: ランダムな盤面を5回試して最悪の回で評価する慎重なプレイヤー）

| ボット       | クリア率 | 参考: 平均で評価（フェーズ3c） |
| ------------ | -------- | ------------------------------ |
| greedy       | 69%      | ほぼ同じ                       |
| mid          | 98%      | ほぼ同じ                       |
| search（40） | 68%      | —                              |

- 慎重に評価しても結果はほとんど変わらない（ポンコツロボをあまり使わないため、運の要素が効いていない）
- ボス別で低いのは「床の補修工事」（greedy 59%）。ほかは 97% 以上
- ポンコツロボの倍率を ×1〜×3（`junkbotMinSteps: 2`）にしても greedy 69% → 69%、mid 98% → 98%。
  ボットの購入率が 4% と低く、難しさへの影響はない → **倍率幅は変えない（手触りの問題として、実際に遊んで判断）**

### デイリー（`--mode daily`、200 シード）

| 案                                      | greedy | mid | 1シフト目のクリア（greedy / mid） |
| --------------------------------------- | ------ | --- | --------------------------------- |
| 現在（ノルマ 5 / 20 / 60）              | 36%    | 47% | 68% / 72%                         |
| A: ノルマを 3 / 12 / 40                 | 46%    | 59% | 82% / 87%                         |
| B: 特殊ルールから「出荷検査強化」を外す | 41%    | 54% | 70% / 73%                         |
| C: A と B の両方                        | 48%    | 60% | 82% / 85%                         |

- **1シフト目で約3割が脱落する**のが問題（通常ランの1シフト目は 100%）。デイリーは1日1回なので、すぐ終わると満足感が低い
- ノルマを通常ランと同じ 3 にしても 1シフト目は 82〜87% に留まる。原因はノルマ以外にもある:
  特殊ルールが3シフトすべてにかかること、ショップが全パーツから出る（出荷口・ギアが並びにくい）こと
- 調整案（採用は要相談）:
  1. **案 C**（ノルマ下げ + 出荷検査強化を外す）: 最も効く。全クリア 48〜60%
  2. **案 A + 1シフト目のショップに出荷口を必ず1つ並べる**（未検証。実装が必要）
  3. **案 A + 特殊ルールを1シフト目にはかけない**（未検証。ルールの説明が「3シフト全体」から変わる）
- どの案も sim の挙動（シフト表・特殊ルール）が変わるため、採用するときは `SIM_VERSION` を上げ、デイリーの切り替え直後にデプロイする

### ツール側の修正（調整の途中で見つかったもの）

- 再起動装置どうしがリセットし合う配置で信号が指数的に増え、メモリを使い切るシードがあった（seed 34）。
  → sim に「同時に存在できる信号数の上限」（`sim.maxLiveSignals = 1000`）を追加して打ち切るようにした
- ボットが「今夜の工事予告」を無視していたため、工事の夜に盤面が崩壊していた。予告マスを避けるよう修正
- 探索ボットに「全部手持ちに戻して組み直す」案を追加（人間は自由に組み替えるため）

### 目標に届いていない点と所見

- **貪欲ボット 31%（目標 50〜70%）**: 失敗 208 件のうち 75 件は「前のシフトと同じスコアのまま」脱落しており、
  組み替えができない貪欲ボット自体の限界。101 件はボスの夜で脱落（特に床の補修工事 62%）。
  これ以上ゲームを易しくすると探索ボットの後半がノルマの数百倍になるため、今回はここで止めた。
  → 「組み替えできる中級ボット」を作って目標を測り直すのが良い（フェーズ2bで検討）
- **ほぼ使われないパーツ**: ポンコツロボ（購入率 5%）・反射板（5%）・合流炉（7%）・回転台（9%）。
  いずれもタイミングや経路の工夫が要るパーツで、ボットでは価値を評価しきれていない可能性が高い。
  人が遊んで確認し、必要なら挙動を見直す（例: 合流炉を「合算 × 合流本数」にする）
- **よく使われるパーツ**: ギア・プレス機・散布機・連鎖メーター（探索ボットの購入率 44〜85%）。
- **後半の爆発**: 探索ボットの最終シフトはノルマの中央値 382 倍、最大で数十億倍。演出（桁の表記）で吸収する前提

## フェーズ3c: 中級ボットでの測り直し（2026-09-28）

中級ボット（`mid`）を追加した。貪欲ボットの手に加えて、置いたパーツの回転・移動と「全部戻して組み直す」を試す（1手先だけを読む）。
「普通に遊ぶ人」の物差しとして、目標クリア率 50〜70% と比べる。

### 結果（seeds 1〜200、探索ボットは 1〜100。バランス定数は変更なし）

| ボット | 初期解放・7×7（初プレイ相当） | 全解放・9×9（やり込み相当） |
| ------ | ----------------------------- | --------------------------- |
| random | 0%                            | 0%                          |
| greedy | 69%                           | 29%                         |
| mid    | 98%                           | 68%                         |
| search | 91%                           | 87%                         |

- 初期解放では中級ボットの最終シフトのスコアが p10 でもノルマの約1500倍。ノルマはほぼ効いていない
  （パーツの種類が少ないぶんギア・プレス機・ソーラーパネルが揃いやすく、組み直しで確実に連鎖を作れる）
- 全解放では中級ボットが目標どおり 68%。脱落はシフトの後半に分散している（p10 がノルマの 1.8〜2.5 倍）
- 探索ボットが初期解放で中級ボットより低いのは、思考時間（3秒/シフト）で深い組み直しが打ち切られるため。物差しとしては中級ボットを使う
- ボス別（mid）: 床の補修工事 98% / 94% が最も低い。他は 91〜100%
- 使われにくいパーツ（全解放、mid / search の購入率）: 合流炉 2% / 8%、反射板 6% / 8%、回転台 4% / 11%、ポンコツロボ 6% / 5%
  （参考: よく使われるのはプレス機 61% / 90%、連鎖メーター 45% / 66%、ギア 33% / 60%）
- 運の要素: ランダムな挙動を持つのはポンコツロボだけで、購入率 5% 前後。試運転と本番の結果が食い違う影響は今のところ小さい

### パーツの見直し（SIM_VERSION 2）と、その後の測り直し

選んでもらった内容:

| パーツ       | 変更                                                                        |
| ------------ | --------------------------------------------------------------------------- |
| 合流炉       | 変えない                                                                    |
| 反射板       | 変えない                                                                    |
| 回転台       | 挙動は変えず、発動回数 4 → 8・価格 2 → 1                                    |
| ポンコツロボ | 方向に加えて、値にもシード乱数の倍率 ×0.5〜×3（0.5 刻み・切り捨て）を掛ける |

結果（seeds 1〜200、探索ボットは 1〜100、評価はランダムな盤面を3回試した平均）:

| ボット | 初期解放 前 → 後 | 全解放 前 → 後 |
| ------ | ---------------- | -------------- |
| greedy | 69% → 23%        | 29% → 18%      |
| mid    | 98% → 21%        | 68% → 34%      |
| search | 91% → 34%        | 87% → 31%      |

- ポンコツロボの購入率が大きく上がった（mid 3% → 18%、search 2% → 40〜54%）。回転台も 4% → 7%（search 11% → 29%）
- 1シフト目から脱落が出るようになった（mid の1シフト目のクリア率 100% → 89%、スコアの p10 が 0）
- 原因の見立て: ボットは「試運転3回の平均」で盤面を評価している。倍率が掛け算で重なるため、たまに出る大当たりで平均が大きくなり、
  ポンコツロボの入った盤面を実力以上に良く見てしまう（本番では外れることが多い）。人も試運転の結果に引っぱられて同じことが起きうる
- 切り分け用に `--eval worst`（何回か試して最悪の回で評価する慎重なボット）をツールに追加した。
  難易度の調整はいったん見送り（2026-09-28 の判断）。再開するときは `pnpm balance --eval worst --samples 5` と比べて、
  「ゲームが難しくなった」のか「ボットの判断が甘い」のかを切り分けてから調整する

## 2026-09-29 床タイルと日ごとのステージ（SIM_VERSION 5・数値は仮）

床タイル（×2床・加算床 +3・×3床・使用不可）、日ごとのステージ（テンプレート11種）、シフト開始時のボーナス床（1〜2枚）、

- 2日目・3日目のステージの使用不可（2〜6マス）と、夜の床の補修工事が重なると、置ける場所がかなり減る

  同じ日のうちの買って売るでは増えない（テストで確認）。直すには、パーツごとに買った値段を覚える必要がある

## 2026-10-03 ランダム配置権（SIM_VERSION 6・数値は仮）

ショップの品ぞろえの1枠が配置権になることがある（出現 25%・価格 4・上限 3・×2 60 / 加算 35 / ×3 5、×3 は3日目から）。
使うと盤面のどこかに床が1枚湧き、日が変わると消える。ボットは組み立て後に、湧きうるマスと種類の重みで期待値を計算し、
見込みが増えるなら余った予算で買って使う（抽選の結果は先読みしない）。

### 計測（greedy・mid・全解放・平均評価・seeds 1〜60）

| 条件                       | greedy 全クリア | mid 全クリア | 購入率（greedy / mid） | 使用率 | 消えた率 | 湧いた床（×2 / 加算 / ×3、greedy） |
| -------------------------- | --------------- | ------------ | ---------------------- | ------ | -------- | ---------------------------------- |
| 配置権を使うボット（既定） | 12%             | 17%          | 70% / 68%              | 100%   | 0%       | 36 / 11 / 2                        |
| 配置権を使わないボット     | 10%             | 15%          | -                      | -      | -        | -                                  |

- 配置権を使うボットの方がわずかに強い（「買わない方が強い」ような不具合はない）
- ボットは買ったその場で使うので、使用率 100%・消えた率 0%。人は「夜まで取っておく」と消えることがある

### 人が確かめるシード

- `?seed=9`（ほかに 21・23・30・44）: 1シフト目のショップに配置権が並ぶ
- 撮影モードの「配置権を1枚もらう」: いつでも配置権を手に入れて、ルーレットを確かめられる
- 置けるマスがない場合は、ふつうの盤面ではまず起きない（空きは 37 マス以上）。テストで確かめている

### 金曜の難易度調整に向けて

- 床（ステージ・ボーナス床・出来事・配置権）が重なると、掛け算で出荷量が大きく伸びる。配置権の ×3 床は3日目から
- 配置権は「余ったお金の使い道」になりやすい。価格・出現率で、パーツの購入と競合させるかを決める
