## 1. Cloudflare の現行仕様（2026年9月時点で確認）

- **CPU 時間:** Workers Paid は1リクエストあたり既定30秒、`limits.cpu_ms` で最大5分まで延ばせる
- **Cron の CPU 時間:** 実行間隔が1時間未満なら30秒、1時間以上なら15分。デイリー生成・相場計算は1日1回なので15分まで使える
- **静的ファイルの配信:** 新規なら Pages ではなく **Workers の静的アセット**が推奨。静的ファイルへのリクエストは無料。API と同じ Worker にまとめられる
- **D1（Paid）:** 1DB 10GB、1回の呼び出しで最大1000クエリ。1つの DB は1本ずつ順にクエリを処理するので、1クエリを短く保つ必要がある
- **Rate Limiting バインディング:** 期間は10秒か60秒のみ。データセンターごとの近似カウント

**前提が崩れる点はありません。** 無料プランでは CPU 時間が足りない、という指示の前提も妥当です。計測（D13）の結果を見て `limits.cpu_ms` を決めます。

> 注: この環境からは公式ドキュメント（developers.cloudflare.com）に直接アクセスできず、検索結果の要約で確認しました。着手時にもう一度確認します。
