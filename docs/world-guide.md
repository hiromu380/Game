# Chain Factory 世界観ガイド

## 一文で表す世界

廃業寸前の「第3夜間工場」で、新任工場長のプレイヤーが整備ロボ・ボルトと廃材を量産し、3日でロケットを完成させる。

## プレイヤーと工場

- プレイヤーは第3夜間工場へ配属された新任工場長。画面は工場長が触る古い操作卓として見せる。
- 第3夜間工場は設備も予算も不足しているが、そこで働く者は工場を嫌ってはいない。
- ノルマは工場を存続させるための本社との約束。失敗を罰するより、もう一度工夫したくなる語り口にする。
- ショップは部品商ギズモが運営する中古部品市場。解放は閉鎖倉庫から旧型設備を再発見することを意味する。
- ロケットはボルトの夢であり、工場のみんなが内緒で手伝っている非公式プロジェクト。

## 表現原則

1. 物語は長文で止めず、構内放送、整備票、承認印、型番、短い会話として見せる。
2. ルール説明を隠さない。「出来事の一文」の後に、数値効果を明確に表示する。
3. 失敗はプレイヤーへの非難にしない。設備のポンコツさと次の工夫へ変換する。
4. 朝・昼・夜、ロケット建造、合格印、煤など、進行を工場の見た目と音へ残す。
5. 写実的な錆や汚れには寄せず、既存スタイルどおり太い線、平面色、小さなズレや遊びで使用感を出す。

## セリフの書き方

AI が書いたような文章（全員が同じ声・同じ型の短文・意味ありげな「……」）にしない。

### 書き方の決まり

- 「短文。ひねった短文。」の格言の型を続けない。パーツの説明文は形式を混ぜる（貼り紙・整備票・取扱説明書の抜き書き・誰かの発言・ただの事実）
- 型番・ライン番号・金額・ページ数など、具体的な細部を1つ入れる
- 「……」は1シーンに1回まで。倒置・体言止めで終わる文を続けない
- 暗い事実（閉鎖・廃棄・未払い）は淡々と、または明るく言う。嘆かない
- 操作の説明（ボタン・ルール・数値）はこの決まりの対象外。わかりやすさを優先する
- 英語版も同じ声で書く（ボルトはくだけた口語、工場長は短くぶっきらぼう、ミリは役所言葉）
