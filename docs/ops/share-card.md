# スコア共有カード（フェーズ4 追加 G）

結果画面（通常ラン・週替わりの挑戦の終了時）と、週替わりの結果発表の「結果を共有」から、カード画像（1200×675・1080×1080）の保存・コピーと、X の投稿画面を開ける。

## 設定値

| 項目                                 | 場所                                                                  | 内容                                           |
| ------------------------------------ | --------------------------------------------------------------------- | ---------------------------------------------- |
| カードに載せる URL（製品版）         | 環境変数 `VITE_STORE_URL`（`config/edition.ts` の `storeUrl`）        | Steam ストアのページ。未設定なら下の URL       |
| カードに載せる URL（体験版）         | 環境変数 `VITE_SITE_URL`（`config/share.ts` の `siteUrl`）            | Web 体験版の URL。未設定なら開いているオリジン |
| カードの大きさ・出荷量の文字の大きさ | `apps/client/src/config/share.ts`                                     | 1200×675・1080×1080、文字 132〜44px            |
| 投稿の本文（#ChainFactory）          | `apps/client/src/i18n/ja.json`・`en.json` の `share.*`・`shareCard.*` | 日本語・英語                                   |
| カードの色                           | `apps/client/src/assets/palette.ts`                                   | 画面と同じパレット（背景・黄・緑）             |
| ロゴ・ボルト・パーツの絵             | 素材マニフェスト（`assets/manifest.ts`）                              | 差し替えれば カードにも反映される              |
| デスクトップ版で開ける外部 URL       | `apps/desktop/src/main/config.ts` の `externalAllowList`              | `https://x.com/intent/post` を許可済み         |

## 決めたこと

- 週替わりのカード・本文には盤面を載せない（その週のうちは全員が同じ条件なので、配置がネタバレになる）。挑戦の終了時はシフトごとの結果と暫定順位、結果発表は確定順位・ベスト・クリアしたシフト数・参加日数を載せる
- URL は本文に入れず、投稿画面の `url` パラメータで付ける
- デスクトップ版は既定のブラウザで投稿画面を開く（X にログインしているのはふだんのブラウザのため。Steam オーバーレイは使わない）
- 共有ボタンの押下回数は数えない（導入済みの Cloudflare Web Analytics はボタンの押下を数えられない。必要になったらサーバーに匿名の回数だけを数える仕組みを足す）
- SteamID などの個人を特定する情報は、カードにも本文にも載せない

## 人が確認すること

- [ ] 製品版の Steam ストアの URL（`VITE_STORE_URL`）と、Web 体験版の URL（`VITE_SITE_URL`）を確定してビルドに設定する
- [ ] ロゴ・ボルトを本番の素材に差し替えたら、カードの見た目を撮影モード（「共有カードを確認」）で確かめる
- [ ] 実際に X へ投稿して、画像の貼り付けと URL のカード表示を確かめる
