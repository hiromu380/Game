# Steam 版の実機確認（人が行う作業）

開発環境では Steam・Windows・Steam Deck の実機で確かめられないため、ここに確認の手順と、未確認の項目（要確認）をまとめる。
前提: desktop.md（SDK の配置・起動）、steam-setup.md（App ID・キー）、steam-build.md（ビルド）。

## 1. 開発用の App ID 480（Spacewar）で確かめられること

Steam クライアントにログインした Windows 機で `pnpm --filter @chain-factory/desktop start`。

- [ ] 起動する。フレンド欄に「Spacewar をプレイ中」と出る（Steam の初期化）
- [ ] Shift+Tab でオーバーレイが開く（**要確認**: Electron のウィンドウにオーバーレイが描かれるか。描かれない場合は、
      体験版の「製品版を見る」が既定のブラウザで開くことだけ確かめる）
- [ ] Steam を終了してから起動しても、通常ランが遊べる（Steam 連携だけが無効になる）
- [ ] デイリーを開くと「Steam の認証サービスに接続できません」等のエラー（480 はサーバーの許可リストにないため。正常）

## 2. 自分の App ID で確かめること（テスト用ブランチのビルド）

**認証（デイリー）**

- [ ] デイリーを開くと、人間確認なしで参加できる（**要確認**: `getAuthTicketForWebApi` の identity がサーバーと一致して通るか）
- [ ] 別の PC・Steam Deck で同じ Steam アカウントで開くと、同じプレイヤー（表示名・進行中のデイリー）になる
- [ ] サーバーのログに `external sign-in failed` が出ていない
- [ ] （**要確認**）Steam の API の応答の形（`response.params.steamid`）と、パブリッシャーキーを partner.steam-api.com で使うこと

**実績・統計**

- [ ] 何も置かずにスイッチを押す → 実績「何も起きない」（隠し）が解除され、オーバーレイに通知が出る
- [ ] シフトをクリア → 「初仕事」、ランを終える → 統計 `STAT_RUNS` が増える（Steam のプロフィールで確認）
- [ ] Steam を終了して遊んで実績を満たし、Steam を起動してからゲームを起動 → そのとき解除される（送り直し）
- [ ] 体験版では実績が解除されない

**Steam クラウド**

- [ ] PC A で遊ぶ → PC B で起動すると続きから遊べる（steam-cloud.md）
- [ ] 設定（音量など）も同期される

**体験版**

- [ ] 体験版のラン終了画面の「製品版を見る」で、製品版のストアページがオーバーレイ（または既定のブラウザ）で開く
- [ ] 体験版で遊んだあと製品版を初めて起動すると「体験版のデータを引き継ぎますか？」が出る。引き継ぐと記録が入っている

**Windows**

- [ ] コード署名なしの exe が、Steam から起動したときに SmartScreen の警告なしで起動する（**要確認**）

## 3. Steam Deck

- [ ] 起動して 1280×800 で全体が収まる（スクロールなし）
- [ ] コントローラーだけで遊べる: タイトル → ラン → 配置（十字キー・A・X・B）→ ショップ・手持ち（L・R）→ 試運転（Y）→ 本番（Start）→ 結果 → 次のシフト
- [ ] 設定・デイリーのダイアログを十字キーと A・B で操作できる
- [ ] デイリーの表示名の入力欄を選ぶと画面上キーボードが出る（**要確認**: `showFloatingGamepadTextInput`）
- [ ] タッチでも操作できる（タップで配置・もう一度タップで回転・長押しで戻す）
- [ ] 文字が小さすぎない（Steam Deck の「確認済み」の基準: **要確認** 最新の基準）
- [ ] **要確認**: Steam Input の標準の配置で、十字キー・ABXY・LB/RB・Start がゲームの Gamepad API の番号と合っているか
      （`apps/client/src/config/controls.ts`。違えばここを直す）
