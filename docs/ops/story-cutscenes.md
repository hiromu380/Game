# ストーリー演出（カットシーン）の確認と撮影

セリフなしのカットシーンの一覧・確かめ方・撮影の手順。絵コンテは `docs/story/storyboard.html`、
シーンの定義は `apps/client/src/story/scenes/`、仕組みは `apps/client/src/story/`（タイムライン・切り絵の計算・再生の判定）。

## シーンの一覧

| シーン                 | ID           | 長さ   | いつ出るか                                               |
| ---------------------- | ------------ | ------ | -------------------------------------------------------- |
| オープニング           | `opening`    | 52 秒  | 初めてのランを開いたとき                                 |
| 1日目のおわり          | `interlude1` | 8 秒   | 1日目をクリアしたとき                                    |
| 2日目のおわり          | `interlude2` | 8 秒   | 2日目をクリアしたとき（3日目は省いてエンディングへ）     |
| ノルマに届かなかった夜 | `gameOver`   | 4.2 秒 | ノルマ未達のとき                                         |
| エンディング           | `ending`     | 57 秒  | 全シフトをクリアしたとき（製品版）                       |
| つづきの予告           | `demoTeaser` | 6 秒   | 体験版で全シフトをクリアしたとき（エンディングの代わり） |

- どれも初回だけ自動で再生する（見た記録はセーブの `story.seen`）。週替わり・練習・延長戦では出さない
- 長押し（0.6 秒）でスキップ。マウス・タッチ・キー・コントローラーのどれでもよい
- 上限 60 秒を過ぎたら、素材の読み込みに失敗したら（5 秒）、必ずゲームへ戻る

## 人が確かめる手順

1. **初回の状態に戻す**: ブラウザの開発者ツールで localStorage の `chain-factory:save` を消す（設定は残る）。
   または `chain-factory:save` の `story.seen` を `[]` にする。タイトル → 「はじめる」でオープニングが出る
2. **各シーンを直接再生する**: 撮影モード（`pnpm --filter @chain-factory/client dev:capture`）でゲームに入り、
   撮影モードのパネルの下のシーンのボタンを押す（見たかどうかに関係なく再生する）
3. **見直し**: 見たシーンがあると、タイトルに「思い出」が出る。選ぶと再生する
4. **設定の反映**: 設定の「演出の強さ: 弱」「揺れ: オフ」「点滅を減らす」で、揺れと光が弱まる・消えること
5. **画面の大きさ**: 1920×1080・1366×768・1280×800 で、シーン全体（16:9）が画面に収まり、重要な要素が切れないこと

## 性能

- 計測（2026-10・この開発環境のヘッドレス Chromium = ソフトウェア描画・1280×800）:
  何も描かない全画面の PixiJS が 1コマ 46.6ms、カットシーンは 1コマ 126〜150ms（全画面の背景を数枚重ねるため、塗りの量に比例）
- ソフトウェア描画の値で、GPU のある実機とは大きく違う。**Steam Deck の実機で、カットシーンが滑らかに動くかを人が確かめる（要確認）**
- 経過時間は実時間で測るので、コマが落ちても話の進み方と音はずれない（動きがカクつくだけ）

## トレーラー・X の動画に使えそうなカット

- オープニング 12〜17 秒: 屋根の上で流れ星 → 絵の吹き出し（ロケットと星）。「夢」が一目で伝わる
- オープニング 25〜35 秒: 大きなクレーンの工場長がノルマの箱を指し、部品を吊って見せる → ボルトがうなずく（取引）
- エンディング 22〜26 秒: 打ち上げ（工場街が下へ流れ、工場長が見上げる）
- エンディング 42〜48 秒: 月の地平線へ光の連鎖が走り、見知らぬ工場の窓が灯る（次回作の予告に向く。製品版のネタバレになるので、使うかは判断する）
