# スタイルガイド（Chain Factory の素材）

素材（パーツ・マスコット・盤面・ボス・UI アイコン・ロゴ・実績アイコン・ロケット）はすべてこのガイドに従う。
色は `apps/client/src/assets/palette.ts` の1か所で定義し、素材・画面・盤面はそこから色を取る。

## 1. 雰囲気

- 親しみのあるデフォルメの工場。リアルな質感は描かない
- **少しポンコツで愛嬌がある**: ネジが1本飛んでいる、少し傾いている、片目がずれている などの小さな遊びを入れる（全部の素材に入れる必要はない。1つの画面で2〜3か所あれば十分）
- 暗い工場の床（チャコール）の上で、パーツが明るい色で目立つ

### パーツの系統色

パーツは「系統」ごとに主色を決め、ひと目で役割がわかるようにする（`FAMILY_COLORS`）。

| 系統   | 主色             | 例                                       |
| ------ | ---------------- | ---------------------------------------- |
| 基本   | 灰 `#90a4ae`＋黄 | スイッチ・コンベア・出荷口・ポンコツロボ |
| 倍率   | 橙 `#fb8c00`     | 増幅ギア・プレス機・合流炉・連鎖メーター |
| 分岐   | 紫 `#8e24aa`     | 分岐器・散布機・爆発ドラム缶・コピー機   |
| 再発動 | 水色 `#00acc1`   | 反射板・回転台・再起動装置・潤滑油タンク |
| 配置   | 緑 `#43a047`     | 共鳴コイル・ソーラーパネル・検品台       |
| 経済   | 桃 `#ec407a`     | 貯金箱                                   |

- 主色は「そのパーツのいちばん大きな面」に使う。細部は明るい色（`light`）・金属色（`INK.steel`）で描く
- 信号の色（黄→橙→赤→桃→紫→水色）とパーツの主色が同じにならないよう、パーツの面積の大きい部分に純色の黄は使わない（スイッチの台座・コンベアの矢羽根などハザード柄は例外）

## 3. 形と線

- キャンバスは 64×64（UI アイコンは 24×24）
- **輪郭線**: 64px 基準で 4px（UI アイコンは 24px 基準で 2px）。角は丸める（`stroke-linejoin: round`）
- **塗り**: フラット。影は「地の色を 15% 暗くした色」の1段だけ（下側・右側に置く）。ハイライトは白の細線1本まで。**グラデーションは使わない**
- **余白**: パーツは中央の 70%（約 45px 四方）にモチーフを収める。盤面ではパーツの上に向きの矢印（辺の中央）・倍率バッジ（左下）・残り発動回数（右上）が重なるため
- **向き**: 回転して向きを表すパーツ（コンベア・分岐器・散布機）は上向きで描く。ほかのパーツは回転させず、盤面側の矢印バッジで向きを示す

### 光の表現（演出だけの例外）

パーツ・UI は上の「フラット＋1段の影」を守る。連鎖演出でだけ、次の範囲で光を使ってよい（値は `apps/client/src/config/effects.ts`）。

- 使う場面: ピーク（連鎖の最後の出荷）・ノルマを超えた瞬間・出荷量の桁が上がった瞬間の3つだけ
- 範囲: 盤面の内側だけ（画面全体・UI には重ねない）
- 明るさ: 淡い黄色（`FX_COLORS.flash`）の単色の面を不透明度 0.35 まで（演出「中」は 0.2、「弱」と「点滅を減らす」では出さない）。白一色の全面フラッシュは使わない
- 回数: 1秒に3回まで（光過敏性への配慮。演出の流れを作る関数で間引く）
- グラデーション・ブルームは使わず、フラットな面を短くフェードさせる

## 4. 読みやすさの基準

- パーツ: **48px でシルエットだけで区別できる**こと（プレビューページ `apps/client/art/preview.html`（`pnpm --filter @chain-factory/client art` で生成し、ブラウザで直接開く） で並べて確認する）
- UI アイコン: **24px で意味がわかる**こと。線を減らし、細部は描かない
- ロゴ: 120×45 に縮めても文字が読めること
- 色覚の違いに配慮し、系統は色だけでなく形でも区別できるようにする（倍率=×や歯車、分岐=矢印が増える、再発動=回る矢印、配置=周囲への波紋、経済=硬貨）

## 5. マスコット「ボルト」

- 四角い頭に丸いアンテナランプのデフォルメ作業ロボ。少し左に傾いている（`rotate(-4°)`）
- 片目が大きく、片目が小さい（ポンコツ感）。口はギザギザ線
- 表情: 待機（idle）・喜び（happy）・驚き（surprised）・失敗（fail）。体は共通で、目・口・アンテナのランプだけを変える
- アプリアイコン・OGP 画像にもボルトを使う

## 6. 素材の作り方

- 仮素材は `apps/client/art/` のスクリプトで SVG を生成する（`pnpm --filter @chain-factory/client art`）。生成物は `apps/client/src/assets/` に書き出し、リポジトリに含める
- 画面からはアセットマニフェスト（`src/assets/manifest.ts`）経由で参照する。本番イラストに差し替えるときは、同じファイル名で置き換え、生成スクリプトの該当項目を外す
- 生成AIで作った素材は `docs/ops/ai-disclosure.md` に記録する。人の制作物に差し替えたら「人の制作」に更新する
