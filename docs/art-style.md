# スタイルガイド（Chain Factory の素材）

素材（パーツ・マスコット・盤面・ボス・UI アイコン・ロゴ・実績アイコン・ロケット）はすべてこのガイドに従う。
色は `apps/client/src/assets/palette.ts` の1か所で定義し、素材・画面・盤面はそこから色を取る。

## 1. 雰囲気

- 親しみのあるデフォルメの工場。リアルな質感は描かない
- **少しポンコツで愛嬌がある**: ネジが1本飛んでいる、少し傾いている、片目がずれている などの小さな遊びを入れる（全部の素材に入れる必要はない。1つの画面で2〜3か所あれば十分）
- 暗い工場の床（チャコール）の上で、パーツが明るい色で目立つ

### パーツの系統色

パーツは「系統」ごとに主色を決め、ひと目で役割がわかるようにする（`FAMILY_COLORS`）。

| 系統   | 主色             | 例                                       |
| ------ | ---------------- | ---------------------------------------- |
| 基本   | 灰 `#90a4ae`＋黄 | スイッチ・コンベア・出荷口・ポンコツロボ |
| 倍率   | 橙 `#fb8c00`     | 増幅ギア・プレス機・合流炉・連鎖メーター |
| 分岐   | 紫 `#8e24aa`     | 分岐器・散布機・爆発ドラム缶・コピー機   |
| 再発動 | 水色 `#00acc1`   | 反射板・回転台・再起動装置・潤滑油タンク |
| 配置   | 緑 `#43a047`     | 共鳴コイル・ソーラーパネル・検品台       |
| 経済   | 桃 `#ec407a`     | 貯金箱                                   |

- 主色は「そのパーツのいちばん大きな面」に使う。細部は明るい色（`light`）・金属色（`INK.steel`）で描く
- 信号の色（黄→橙→赤→桃→紫→水色）とパーツの主色が同じにならないよう、パーツの面積の大きい部分に純色の黄は使わない（スイッチの台座・コンベアの矢羽根などハザード柄は例外）

### 床タイル

床は盤面の下層なので、パーツより控えめに描く（地の床の上に、色つきの鉄板を半透明で重ねる。`BOARD_COLORS`・`art/board.ts`）。
種類は色だけでなく溝の模様でも見分けられるようにし、数字（×2・+3・×3）はマスの左上に重ねる（パーツを置いても見える位置）。

| 床       | 色               | 模様                   |
| -------- | ---------------- | ---------------------- |
| ×2床     | 琥珀 `#ffb300`   | 斜めの溝2本            |
| 加算床   | 緑 `#43a047`     | 十字の溝               |
| ×3床     | 桃 `#e91e63`     | 斜めの溝3本            |
| 使用不可 | 赤 `#c62828`＋白 | 工事柵とコーン（既存） |

- ボーナス床（シフト開始時）・今日の出来事の床は期間限定なので、水色 `#4dd0e1` の点線の枠で見分けられるようにする
- 床の効果を受けた瞬間は、パーツの発動と同じく、そのマスの内側だけを床の色で短く光らせる（盤面全体の光ではないので、下の「光の表現」の対象外）

## 3. 形と線

- キャンバスは 64×64（UI アイコンは 24×24）
- **輪郭線**: 64px 基準で 4px（UI アイコンは 24px 基準で 2px）。角は丸める（`stroke-linejoin: round`）
- **塗り**: フラット。影は「地の色を 15% 暗くした色」の1段だけ（下側・右側に置く）。ハイライトは白の細線1本まで。**グラデーションは使わない**
- **余白**: パーツは中央の 70%（約 45px 四方）にモチーフを収める。盤面ではパーツの上に向きの矢印（辺の中央）・倍率バッジ（左下）・残り発動回数（右上）が重なるため
- **向き**: 回転して向きを表すパーツ（コンベア・分岐器・散布機）は上向きで描く。ほかのパーツは回転させず、盤面側の矢印バッジで向きを示す

### 光の表現（演出だけの例外）

パーツ・UI は上の「フラット＋1段の影」を守る。連鎖演出でだけ、次の範囲で光を使ってよい（値は `apps/client/src/config/effects.ts`）。

- 使う場面: ピーク（連鎖の最後の出荷）・ノルマを超えた瞬間・出荷量の桁が上がった瞬間の3つだけ
- 範囲: 盤面の内側だけ（画面全体・UI には重ねない）
- 明るさ: 淡い黄色（`FX_COLORS.flash`）の単色の面を不透明度 0.35 まで（演出「中」は 0.2、「弱」と「点滅を減らす」では出さない）。白一色の全面フラッシュは使わない
- 回数: 1秒に3回まで（光過敏性への配慮。演出の流れを作る関数で間引く）
- グラデーション・ブルームは使わず、フラットな面を短くフェードさせる

### キービジュアル・カプセル画像の例外（ストア素材だけ）

ストアのキービジュアルとカプセル画像（`apps/client/art/keyvisual/`）に限り、次を使ってよい。ゲーム内の絵には持ち込まない。

- 光の連鎖・放射の光・火花・数字の発光・夕焼けに、半透明の重ね塗りと SVG のぼかし（`feGaussianBlur`）を使う
- 空は、フラットな色の帯を重ねて表す（グラデーションは使わない）
- それ以外（ボルト・パーツ・盤面・工場街・ロケット・ロゴ）はゲーム内の素材をそのまま組み合わせ、絵柄をゲームとそろえる

## 4. 読みやすさの基準

- パーツ: **48px でシルエットだけで区別できる**こと（プレビューページ `apps/client/art/preview.html`（`pnpm --filter @chain-factory/client art` で生成し、ブラウザで直接開く） で並べて確認する）
- UI アイコン: **24px で意味がわかる**こと。線を減らし、細部は描かない
- ロゴ: 120×45 に縮めても文字が読めること
- 色覚の違いに配慮し、系統は色だけでなく形でも区別できるようにする（倍率=×や歯車、分岐=矢印が増える、再発動=回る矢印、配置=周囲への波紋、経済=硬貨）

## 5. マスコット「ボルト」

- 四角い頭に丸いアンテナランプのデフォルメ作業ロボ。少し左に傾いている（`rotate(-4°)`）
- 片目が大きく、片目が小さい（ポンコツ感）。口はギザギザ線
- 表情: 待機（idle）・喜び（happy）・驚き（surprised）・失敗（fail）。体は共通で、目・口・アンテナのランプだけを変える
- アプリアイコン・OGP 画像にもボルトを使う

### 全身（設定画: docs/characters/preview.html・生成: apps/client/art/characters/bolt.ts）

- 体型: 二本脚の小型ロボ（段階1の3案から A を採用。比較は docs/characters/roughs.html）。約 2.3 頭身（頭 55・胴 34・脚 28。腰が原点）
- 顔（頭）はアイコンと同じ絵を使い、変えない。全身の絵でも頭の傾き（-4°）とポンコツ感（目の大きさ・抜けたネジ）を残す
- 色（palette.ts）

| 部分             | 色                                                       | 影・アクセント                                                                       |
| ---------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| 頭・胴（本体）   | `BOLT_COLORS.body` #7cb342                               | 影 `shade(body)`・ハイライト `bodyLight` #9ccc65・輪郭 `BOLT_COLORS.outline` #33691e |
| 腕・すね         | `INK.steel` #90a4ae                                      | 太もも・首 `INK.steelDark` #546e7a                                                   |
| 手               | `INK.steelLight` #cfd8dc                                 | ―                                                                                    |
| 長靴             | `ROCKET_COLORS.accent` #e53935（ロケットの赤とそろえる） | 縁 `accentShade` #b71c1c                                                             |
| 胸のメーター     | `INK.white`                                              | 針 `ROCKET_COLORS.accent`（ノルマのメーター）                                        |
| アンテナのランプ | `BOLT_COLORS.lamp` #ffeb3b                               | 消えているとき `INK.steel`・眠いとき `steelDark`                                     |

- 表情（頭の差し替え）: 待機・喜び・驚き・失敗（アイコンと共通）＋しょんぼり・決意・疲れた笑顔・目を輝かせる・眠い・見上げる
  - しょんぼりの眉は内側が上がる（八の字）。内側が下がると怒り顔に見えるので、決意だけに使う
- 切り絵アニメ: 頭・胴・上腕・前腕・手・太もも・すね・足・小物・効果の線に分け、関節（回転の中心）とポーズを `rig.json` に持つ。
  ポーズは部品の回転・位置・差し替えだけで作り、1枚絵を描き分けない
- 身振りは大きく、シルエットだけで読めるようにする（腕を上げる・頭を下げる・体を傾ける）。効果の線（うなずき・首振りの弧・汗・星）は白か系統色で補う

### 工場長（天井クレーン。生成: apps/client/art/characters/chief.ts）

- ストーリーで「ノルマと引き換えにロケットの部品を渡す」役。気難しいが悪人ではない。2案のラフ（docs/characters/roughs-chief-rocket.html）から「天井クレーン」を採用
- 柱の上の運転席が頭。本体は警戒色の黄（`FAMILY_COLORS.hazard.main`）・影は `shade`・輪郭は `INK.outline`。ヘルメットは白に赤い印
- 目は窓の帯のランプ（`MATERIAL_COLORS.sun`）。機嫌は鉄板のまぶたで表す: 気難しい（内側が下がる・普段）・和らぐ（まぶたが上がり笑いじわ・エンディング）・驚く
- 身振りは腕（ジブ）とフック: 指さす・差し出す（フックで部品を吊る）・腕を組む相当（ジブを体の前に畳む）・首を振る／うなずく（運転席を傾ける）・帽子を上げる（ヘルメットを持ち上げる。エンディングだけ）
- フックは重さで常に真下へ下がる（ポーズでジブを回しても、フックの角度で打ち消す）
- 高さはボルトの約 2 倍。並べたときに、ボルトが見上げる力関係になる

### ナット（仮名・見知らぬロボ。生成: apps/client/art/characters/nut.ts）

- エンディングの伏線（遠くの工場のアンテナの光・工場長の古い写真）にだけ出る、ボルトより先に月へ旅立った先輩。3案のラフ（docs/characters/nut-roughs.html）から「旅人（細長い二本脚）」を採用
- ボルトとシルエット・色で見分ける: 六角ナットの頭（ボルトは四角）・大きな1つ目のレンズ（ボルトは左右で違う2つの目）・高いアンテナ・約 3 頭身で細身（ボルトは約 2.3 頭身でずんぐり）
- 色（`NUT_COLORS`）: 本体 #00acc1・明るい面 #4dd0e1・輪郭 #004d5a。アンテナのランプ #80deea は伏線の光（遠くで点滅を返す）と同じ。マフラーと靴はオレンジ #ffb74d（影 #e65100）
- 表情はレンズ（黒目の位置・大きさ）とまぶた、アンテナの光で出す: いつも・にっこり（∩の目・ランプが光る）・驚き・さびしげ・見上げる・まばたき
- 胸は方位磁針（旅人の記号）、背中に小さな荷物。マフラーは風になびく（旅の途中であることを示す）
- 部品・関節・ポーズは `rig.json`（ボルトと同じ形式）。次回作で迎える身振り（手を差し出す）も用意してある
- ナットのロケット（`apps/client/art/characters/nutRocket.ts`）は、ボルトの手作りロケットより性能が良さそうに見せる: 細長い流線形・補助ブースター2本・ノズル3つ（ボルトは1つ）・大きな翼・銀色の先端・丸窓2つ・アンテナの皿。継ぎはぎやテープは描かない（きれいに作られた機体）

### ロケット（生成: apps/client/art/rocket.ts）

- 赤白のロケットに、ガラクタの部品を混ぜた手作りの姿: じょうごのノズル・ドラム缶（たがの線と手描きの「1」）・テープの継ぎはぎ・洗濯機の扉の窓・赤いバケツの先端
- 9 部品（1日3部品。シフトをクリアするたびに1部品）。まだの部品は点線の輪郭だけ。上部の背景・日ごとの幕間・共有カードで同じ絵を使う
- 打ち上げ用に炎（`flame.svg`）と煙（`smoke.svg`）を別の部品として持つ

### カットシーン（セリフなしのストーリー演出。絵コンテ: docs/story/storyboard.html）

- 言葉を使わず、表情・身振り・絵の吹き出し・光と色で伝える。画面の文字はタイトル・ロゴ・数字（カウントダウン）と、体験版の予告の文言だけ
- キャラクターは設定画の部品（rig.json）を時間で動かす切り絵アニメ。背景・小物は `apps/client/art/story/assets.ts`（1280×720 の座標）
- 色の使い分け: 夢・希望は星の光（暖色）、失敗は冷たい色（暗い青を重ねる）、最後は暖色に戻して終える
- 次回作への伏線の記号: 水色（`FAMILY_COLORS.retrigger`）のアンテナの光と、光の連鎖の線。ボルト（緑と黄のランプ）と見分けられる色にする
- 光は演出と同じ決まり（1秒に3回まで・不透明度 0.35 まで・画面全体の白いフラッシュは使わない）。設定の「演出の強さ」「揺れ」「点滅を減らす」に従う
- 重要な要素は中央の安全な範囲（1120×630）に置く（1366×768・1280×800 でも切れない）

## 6. 素材の作り方

- 仮素材は `apps/client/art/` のスクリプトで SVG を生成する（`pnpm --filter @chain-factory/client art`）。生成物は `apps/client/src/assets/` に書き出し、リポジトリに含める
- 画面からはアセットマニフェスト（`src/assets/manifest.ts`）経由で参照する。本番イラストに差し替えるときは、同じファイル名で置き換え、生成スクリプトの該当項目を外す
- 生成AIで作った素材は `docs/ops/ai-disclosure.md` に記録する。人の制作物に差し替えたら「人の制作」に更新する
