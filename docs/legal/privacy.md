## 2. 端末に保存する情報

本サービスは、利用者の端末（ブラウザ）に次の情報を保存します。サーバーには送信しません（プレイヤー ID とトークンを除く）。

- 通常ランの進行状況・実績（メタ進行）
- ユーザー設定（言語・演出・音量）
- 匿名のプレイヤー ID と認証用トークン（デイリーチャレンジ用）
- オフラインで遊ぶためのゲームのファイル（Service Worker のキャッシュ）

ブラウザのデータを消去すると、これらは削除されます。プレイヤー ID が消えた場合、以前のランキング記録を引き継ぐことはできません。

## 3. 外部サービスの利用（第三者への提供・委託）

本サービスは Cloudflare, Inc. のサービスを利用しており、上記の情報は同社のサーバーで処理・保存されます。

- **Cloudflare Workers / D1**: 本サービスの配信とデータの保存
- **Cloudflare Turnstile**: デイリーチャレンジへの初回参加時に、ロボットによる大量登録を防ぐための確認を行います。確認のために、端末・ブラウザの情報が Cloudflare に送信されます
- **Cloudflare Web Analytics**: Cookie を使わないアクセス解析

Cloudflare による情報の取り扱いは、同社のプライバシーポリシーに従います。【未確定: 外国にある第三者への提供に関する記載（個人情報保護法への対応）。同社の所在国・措置を確認して記載】

法令に基づく場合を除き、上記以外の第三者に情報を提供しません。

## 4. 公開される情報

デイリーチャレンジのランキングでは、**表示名・スコア・到達シフト数・最大連鎖数** が、他の利用者に公開されます。表示名に個人を特定できる情報を入れないでください。
