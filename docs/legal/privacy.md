## 2. 端末に保存する情報

本サービスは、利用者の端末（Web 版はブラウザ、Steam 版は PC のユーザーデータのフォルダ）に次の情報を保存します。運営者のサーバーには送信しません（プレイヤー ID とトークンを除く）。

- 通常ランの進行状況・実績（メタ進行・実績の解除状況）
- ユーザー設定（言語・演出・音量）
- 匿名のプレイヤー ID と認証用トークン（デイリーチャレンジ用）
- （Web 版）オフラインで遊ぶためのゲームのファイル（Service Worker のキャッシュ）

Web 版はブラウザのデータを消去すると、これらは削除されます。プレイヤー ID が消えた場合、以前のランキング記録を引き継ぐことはできません（Steam 版は Steam アカウントで取り直せます）。

**Steam 版の追加事項**

- 進行状況とユーザー設定は、Steam クラウド（Valve Corporation のサービス）で同期されます（Steam の設定で無効にできます）。認証用トークンは同期しません
- 実績の解除と、回数の統計（遊んだランの回数・全シフトをクリアした回数・デイリーチャレンジに参加した日数）を Steam に送信します。これらは Steam のプロフィールで、利用者の Steam の公開設定に従って表示されます
- 製品版を初めて起動したとき、同じ PC に体験版の記録があれば、引き継ぐかどうかを確認します（PC の中で読み込むだけで、運営者のサーバーには送信しません）

## 3. 外部サービスの利用（第三者への提供・委託）

本サービスは Cloudflare, Inc. のサービスを利用しており、上記の情報は同社のサーバーで処理・保存されます。

- **Cloudflare Workers / D1**: 本サービスの配信とデータの保存
- **Cloudflare Turnstile**: デイリーチャレンジへの初回参加時に、ロボットによる大量登録を防ぐための確認を行います。確認のために、端末・ブラウザの情報が Cloudflare に送信されます
- **Cloudflare Web Analytics**: Cookie を使わないアクセス解析

- **（Steam 版）Valve Corporation の Steam**: 認証チケットの確認（Steam Web API）、実績・統計、Steam クラウドによる同期、ストアページの表示

Cloudflare・Valve による情報の取り扱いは、各社のプライバシーポリシーに従います。【未確定: 外国にある第三者への提供に関する記載（個人情報保護法への対応）。各社の所在国（いずれも米国）・措置を確認して記載】

法令に基づく場合を除き、上記以外の第三者に情報を提供しません。

## 4. 公開される情報

デイリーチャレンジのランキングでは、**表示名・スコア・到達シフト数・最大連鎖数** が、他の利用者に公開されます。表示名に個人を特定できる情報を入れないでください。

## 5. 不適切な表示名
