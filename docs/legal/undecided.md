| ---------------- | ------------------ | ------------------------------------------------------------------------ |

## プライバシーポリシー（docs/legal/privacy.md）

| 項目                                | 決めること                                                                                          |
| ----------------------------------- | --------------------------------------------------------------------------------------------------- |
| プレイヤー ID・プレイ記録の保存期間 | 例: 最終利用から N 年。期限が来たら消す場合は、定期ジョブを追加する（実装が必要）                   |
| Web Analytics の保存期間            | Cloudflare の現在の保存期間を確認して記載                                                           |
| ★ 外国にある第三者への提供          | Cloudflare・Valve（いずれも米国）への提供について、個人情報保護法で必要な記載（所在国・措置など）   |
| 削除の依頼の手順                    | 本人確認の方法（プレイヤー ID を表示・伝える方法）。Steam 版は SteamID のハッシュ値との紐づけも消す |
| ★ お子様の利用                      | 対象年齢・保護者の同意の方針（Steam のレーティング・IARC の回答と合わせる）                         |

## フェーズ4で追記した内容（確認してほしい点）

- Steam 版: SteamID は秘密鍵付きのハッシュ値だけを保存（SteamID そのものは保存しない）。Steam の表示名は使わない
- Steam 版: Steam クラウドでセーブ・設定を同期（トークンは同期しない）、実績と回数の統計を Steam に送信
- 体験版 → 製品版の引き継ぎは PC の中だけで行い、サーバーには送らない
