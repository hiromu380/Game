# CLAUDE.md — 一門（仮）

相撲部屋の経営シミュレーション。`games/sumo/` 以下の設計書。作業前に必ず読み、ここに反する実装をしないこと。
仕様の変更が必要だと判断した場合は、実装する前に提案して承認を得ること。
リポジトリ直下の CLAUDE.md は別のゲーム（Chain Factory）の設計書。コードは共有しない（実装ルールの考え方だけ同じにする）。

---

## 1. ゲーム概要

- ジャンル: 相撲部屋の経営シミュレーション × 世代をまたぐ系譜
- 方針: **リアル志向**。お金・番付・制度・一年の流れは実際の大相撲に合わせる（調べた値と出典は `docs/realism.md`）。
  ゲームとして省く・まとめる所は、その旨を `docs/realism.md` に書く
- コンセプト: 親方として部屋を開き、弟子を育て、定年で部屋を弟子に継がせる。代を重ねるほど「一門」の系譜図が広がる
- 核の仕組み: **一門の系譜**。1人の親方が部屋を持つ期間が1代。跡継ぎ（年寄名跡を継げる元関取）がいなければ部屋は閉鎖、一門の系譜が途切れる
- 見た目: 絵（部屋の箱庭・顔の絵・表紙・取組の土俵）はドット絵でそろえる。素材は取り込んだスプライトと、コードで描くドット絵（`docs/art-style.md`）
- 遊ぶ環境: Web（PC・スマホ両対応）
- 世界観: 架空の相撲界。制度と金額は実際に合わせるが、力士・部屋・協会の固有名は架空にする（実在の人物・団体の名前は使わない）
- トーン: 落ち着いた、少しとぼけた語り口。笑いは「実際の制度の細かさ」から出す（誇張しない）

## 2. コアループ

### 時間

- 1年 = 6場所（初・春・夏・名古屋・秋・九州）。時間は場所単位で進む
- 1代 = 親方が部屋を開いてから定年（65歳）まで（約25年・約150場所）。何も起きない場所は「任せる」（1場所・1年）で早送りできる:
  場所前は「いつも通り」、中日は「そのまま」で進み、弟子のけが・関取以上への昇進・見立て★3以上の入門希望者・出来事・引退の申し出・親方の判断・お金が3場所以内に尽きそう、で止まる。
  任せた間の場所ごとの要点（勝ち越し・番付の上下・お金・昇進・けが）と止まったわけを出す（`client/src/delegate.ts`）
- 判断が要る場面（新弟子の入門・けが・引退・昇進・お金の不足）でだけ止まる

### 1場所の流れ

1. 場所前
   - 弟子ごとに稽古の方針を選ぶ（押し・四つ・技・体づくり・休養）。前の場所の方針を続けてもよい（毎回選び直さなくてよい）
   - 弟子ごとに稽古の量を選ぶ（軽め・ふつう・猛稽古）: 伸び・疲れ・稽古でのけがの危なさが変わる（`balance/growth.ts` の intensity。推定）。休養のときは効かない
   - 場所前の4週間: 毎週1つ、親方の行動をコマンドで選ぶ（`sim/src/game/prep.ts`・`balance/prep.ts`。効果は推定）。4週を終えるまで本場所へは進めない（「残りはいつも通り」で任せられる。「任せる」でもよい）
     - 個別指導（弟子1人。方針の能力が伸びて疲れる）・申し合い（弟子2人。格上と当たった方がよく伸びる。けがの危なさ）・胸を借りる（弟子1人を関取衆の稽古へ。個別指導の倍伸びるが、ひどく疲れ、けがも多い。部屋の口座から）・出稽古（けがのない全員が少し伸びる。部屋の口座から）・
       休ませる（全員の疲れが抜ける）・挨拶回り（タニマチ1人。親方の貯金から）・スカウト回り（1つの場所に1回）・いつも通り
     - コマンド（と相手）を選ぶと「これで決める？」が出て、「決定」で行う（押し間違えないように。「残りはいつも通り」も同じ）
     - 結果はその場で弟子に効き、週ごとの結果を出す（`state.prep`。場所を進めると、はじめから）。乱数は用途別の流れ（場所と週で決まる）
     - 伸びは1回ごとの決まった量（素質が上限。若さ・性格・設備などが掛かる）。ふだんの稽古（素質までの残りの割合）より読みやすく、毎週の選択が目に見えて効く
   - 素質の壁: 方針の能力が素質の近くまで来た弟子は「壁」に当たる（札を出す）。壁の弟子に個別指導・申し合い・胸を借りる・猛稽古をさせると、素質そのものが上がる（壁を破る。`balance/wall.ts`・`career/wall.ts`。数値は推定）
     - 上がるほど上がりにくく、合計に上限がある。ピークの年齢まで。個性は元の素質で決まり、変わらない。乱数を使わない（危なさは稽古の疲れとけがの側にある）
     - 指しているコマンドの効果を1行で出す（説明を隠していても出す。危ない行動は「けが ◯%」の札も）。行動の後は、伸びた量を弟子の疲れの横と箱庭の頭の上に浮かべ、音を鳴らす（稽古は当たる音・けがは落ちる音）
   - 新弟子の候補が来ることがある（新弟子検査: 身長・体重の基準、または運動能力検査。年齢の上限。外国出身は1部屋1人）
2. 本場所（15日）
   - 関取（十両以上）は15番、幕下以下は7番。番付のすべての力士（架空の他の部屋の力士を含む）が取組をする
   - 結果の一覧と、自分の弟子の見どころだけを見せる
   - 「本場所へ」で進めると、自分の弟子の星取りを1日ずつ見せる（前半 1〜8日目 → 中日の判断 → 後半 9〜15日目 → 見せ場と結果）。飛ばせる。
     勝ち越し・負け越しは決まった日に札が出る（勝ち越しの日は行が光り、拍手）。見終えると少し間をおいて次へ進む（押せばすぐ。動きを減らす設定では待つ）。1年の早送りでは出さない（`client/src/ticker.ts`・`ui/BashoTicker.tsx`）
   - 中日（8日目）で一度止まり、前半の星と幕内の先頭を見せる。休場している弟子（場所中のけが・初日から休場）を後半から出せる（再出場・途中出場）:
     休んだ番は負けのまま残りで白星を取り返せるが、調子が落ち、けがをしやすく、場所の後に治りが遅れる・重くなることがある（`balance/injury.ts` の MID_BASHO。推定）。
     前半は同じ乱数で計算し直すので、止まった状態はセーブに持たない。1年の早送りでは止まらない
   - 中日には、出ている弟子ごとに後半の取り口も選ぶ（攻める・いつも通り・無理をしない）: 9日目からの調子と、後半のけがの危なさ、場所の後の疲れが変わる
     （`balance/injury.ts` の MID_BASHO.stance。推定）。勝ち越しまでの残りを横に出す
   - 大一番の作戦: 後半に勝ち越しをかけた最後の一番（7勝7敗・3勝3敗）を迎える弟子がいれば、その前の日で星取りを止め、相手と型を見せて立ち合いの作戦を聞く（いつも通り・当たる・差す・変化。`balance/tactic.ts`。数値は推定）
     - 効く相手の型は型の三すくみと同じ向き（当たる → 技・差す → 押し・変化 → 四つ）。自分の型に合わない作戦は少し不利。変化は効けば大きいが、読まれると大きく不利で、勝っても名声とタニマチの関係が下がる（報酬と罰に出す）
     - 作戦はその一番の勝つ確率だけを動かし、乱数の使い方は変えない（そこまでの星と大一番の相手は、作戦を選ぶ前と同じ）。任せるときは聞かない
     - 作戦を決めたら、その場で大一番を見せ（取組を見る・結果だけ見る）、星取りの続きへ戻る。結果を知った後に大一番を見せることはしない（結果の後の見せ場には出さない）
3. 場所後
   - 番付編成（勝ち越し・負け越し、空いた枠、定員で決まる）。大関・横綱の昇進は成績の基準で決まる
   - お金の精算（実際の金額。下の「お金」）
4. 年の終わり（九州場所の後）
   - 全員が1歳年をとる。衰えた力士は引退する

### 一門の系譜（世代をまたぐ）

- 弟子が引退するとき、**年寄名跡の襲名資格**（日本国籍＋次のいずれか: 三役1場所・幕内通算20場所・十両以上通算30場所）を満たし、
  空いている名跡があれば、親方として協会に残る（部屋付きの親方）
- 部屋付きの親方は、条件がそろえば**独立して部屋を開く**（分家）。分家の部屋は自動で運営され、成績が一門の名声になる
- 親方が65歳で定年を迎えるとき、部屋付きの親方の1人を跡継ぎに選び、**次の代としてその親方を操作する**
- 跡継ぎがいなければ、本家の部屋は閉鎖。分家が残っていれば、分家のどれかを継いで続けられる。どこも残らなければ一門は途絶え、ゲームが終わる
- 受け継ぐもの:
  - **型**: 親方の現役時代の型の稽古は、その部屋の弟子がよく伸びる
  - **家訓**: 代の終わりに、その代の出来事から候補が出て1つ書き加える（枠に上限。一門のすべての代に効く）
  - **四股名の一字**: 弟子の四股名には親方の四股名の一字が入ることが多い（自動の名づけ）
  - **名声**: 関取・三役・横綱・優勝が出るほど上がり、入門希望者が増え、素質の高い新弟子が来る
- 結果: 何代続いたか・関取／三役／横綱を何人出したか・幕内優勝の回数。系譜図は記録として残る
- 部屋付きの親方は、条件を満たすと独立を申し出る（推定の条件。docs/realism.md「独立（分家）」）。認めると内弟子を連れて分家を開く

### 協会（相撲界全体の親方と名跡）

- 年寄名跡は105。すべてに持ち主がいるか空きで、空きがないと引退した関取は親方になれない（空くまで待つ。待てる年数に上限）
- すべての部屋に師匠が1人（名跡を持つ親方。部屋の名前は師匠の名跡）。部屋付きの親方・参与（定年後70歳まで）も名跡を持つ
- すべての部屋は5つの一門のどれかに属する。分家は本家と同じ一門。自分の一門はゲーム開始時に決まる
- 架空の部屋も同じ規則で動く: 師匠の定年で部屋付きの親方が名跡を交換して継ぐ／継ぐ人がいなければ閉鎖（力士と親方は同じ一門の部屋へ）／部屋付きの親方の独立／引退した関取の襲名
- 画面: 「協会」タブで一門ごとの部屋（師匠・力士・関取の数）と空いている名跡を見る。数値は `balance/association.ts`

### 協会の役職と理事選挙

- 自分の親方の役職: 年寄 → 主任 → 委員 → 役員待遇委員（年の終わりに年齢と名声で上がる）→ 副理事・理事（選挙）→ 理事長（理事の中でいちばん格の高い親方）。代替わりのときは新しい親方の年齢から
- 役職で親方の月給（年寄 78.4万・委員 100.1万円は実額、ほかは推定）と場所ごとの名声が変わる。理事以上は、部屋付きの親方がいないと稽古の伸びが少し落ちる
- 理事選挙は2年に1度（初場所の後）。理事10人・副理事3人を、一門ごとの親方の数でドント式に割り振り、各一門は格の高い親方を推薦する（無投票）。委員以上なら、推薦がなくても立候補できる（造反: 当選は名声しだい、当落で名声が動く）
- 協会タブに理事会の顔ぶれと自分の役職。数値は `balance/office.ts`

### ライバルの部屋

- 別の一門の架空の部屋のうち、師匠の年が近く、部屋の力（番付の地位の点の合計）が近い部屋を「同期のライバル」にする（`state.rival`）。部屋が閉じたら年の終わりに選び直す
- ライバルになって3年たち、もっと番付で競る部屋が出てきたら、年の終わりに替わる（直接対決は数え直し。日誌に残る）。重みと点は推定（`balance/rival.ts`）
- 場所ごとに直接対決（場所・通算）と関取の数を比べ、場所の結果と協会タブに出す。関取の直接対決に勝つと名声が上がる
- 見立ての高い入門希望者は、ライバルも狙っていることがある。その場所のうちに受け入れないと、ライバルの部屋に入る
- ライバルの幕内優勝・大関/横綱昇進・新弟子の取り合いは日誌に残る。ライバルがらみの出来事（出稽古の誘い・新聞の談話）がある。数値は推定（`balance/rival.ts`）

### 部屋の人とちゃんこ

- 若者頭（幕下以下の稽古が伸びる）・世話人（回復が早く、けがが減る）を、親方にならなかった元弟子（最高位が幕下以上・現役が長い）から1人ずつ推薦して雇う。給料は協会が払う（部屋の会計には出ない）。腕前は最高位で決まり、65歳で定年
- ちゃんこの方針（ふつう・大盛り・栄養重視・節約）で、食費・体重の増え方・疲れの回復・けがの確率が変わる
- 数値は推定（`balance/staff.ts`）

### 場所の見せ場

- 場所が終わったら、自分の部屋の見せ場（大関・横綱昇進 → 幕内優勝 → 新入幕・新十両 → ほかの段の優勝 → 三賞）を1枚ずつ見せてから、場所の結果を出す
- 大関・横綱の昇進は伝達式: 口上の四字熟語を3つの候補から選ぶ（横綱は土俵入りの型も）。本人と日誌に残る。選ばずに済ませてもよい
- 幕内の優勝争い: 場所の結果に、10日目から千秋楽までの日ごとの先頭（星と力士）・優勝が決まった日・結びの一番（見られる）を出す。
  自分の弟子が14日目を終えて先頭から1差以内なら、見せ場に「千秋楽の優勝争い」を出し、その弟子の千秋楽の一番を見られる（取組の結果から数える。`sim/src/basho/race.ts`）
- 勝ち越しをかけた大一番: 自分の弟子が7勝7敗（幕下以下は3勝3敗）で最後の番を迎えたら、本場所の星取りの途中、その日に出す（作戦の後）。星取りを見せないで進めたときだけ、見せ場の最初に出す（番付の上から2人まで）。
  取組を見てから（または飛ばして）結果を明かす（`client/src/highlights.ts` の bigBouts）
- 場所の結果に「稽古の成果」: 場所の後の稽古で動いた能力・体重・疲れと、稽古でのけが（`report.training`）
- 場所の結果の先頭に、要点の数字（勝ち越しの人数・番付の上がり下がり・部屋の収支）を並べる

### 引退相撲・断髪式

- 関取だった元弟子は、引退の後に断髪式を行う。関取30場所以上は国技館の引退相撲（引退から3場所以上たった最初の東京場所の後）、それ未満はホテルでの断髪式（次の場所の後）。関取でなかった弟子は行わない
- 場所の見せ場の最後に1枚出す: はさみを入れた人数（最高位で決まり、力士ごとに決まったばらつき）・顔を見せたタニマチとライバルの師匠。親方が「止めばさみ」を入れると髷が落ちる
- 収益は本人のもの（部屋の会計に入れない）。部屋の名声・後援会の会員・タニマチの関係が上がる。日誌に残り、歴代の力士の一覧に予定を出す。予定は元弟子の記録から決まるので、セーブに持たない（`stable/danpatsu.ts`・`balance/danpatsu.ts`）

### 殿堂と歴代記録

- 一門タブに「部屋の殿堂」: 横綱・大関・幕内優勝・三賞5回以上の元弟子（最高位の高い順）。最高位・通算成績・何代目の弟子か・得意技
- 「部屋の歴代記録」: 通算勝ち星・幕内優勝・幕内在位・関取在位・三賞・金星・白星の決まり手の種類・生涯の稼ぎで、元弟子と今の弟子の上位3人（今の弟子に「現役」の印）
- 今の弟子が記録を塗り替えたら、場所の見せ場で知らせる（序盤の小さな記録は知らせない下限つき）。どれも元弟子と弟子の記録から数える純粋関数で、セーブに持たない（`client/src/records.ts`）

### 部屋の日誌とセーブ

- 日誌: 自分の部屋と分家の出来事（入門・昇進・優勝・三賞・引退と襲名・出来事への返事・設備・独立・継承・家訓・分家の継承と閉鎖）を時系列で残す（`state.journal`）。
  名前はそのときのものを書き写す（後で力士が消えても読める）。返事をしないまま流れた出来事は書かない
- セーブはファイルに書き出し・読み込みができる（別の端末へ移す・控えを取る）。読み込みは古い版を変換し、読めないファイルは断る。今の部屋を置き換える前に確かめる

### 弟子の近い目標

- 弟子ごとに「この場所で何勝すれば、何に届くか」を出す（`client/src/targets.ts`。番付編成の規則〔前の位置 − 勝ち越しの数 × 段ごとの枚数〕から見積もる純粋関数。ほかの力士の成績でずれる目安）:
  上の段へ（「5勝で三段目」）・前頭は三役・小結は11勝で関脇・関脇は三役の直近3場所33勝（最後10勝以上）から大関・大関のカド番と綱取り・横綱は優勝。
  関取で13勝以上要る遠い目標は、まず勝ち越し。届かない幕下以下は「◯まであと◯枚」。関取は負け越すと落ちる段も出す
- 弟子のカード・話しかけるカード・星取り（届いた日に「三段目へ！」の札と拍手）・中日（「あと2勝で十両」）に出す

### 部屋の歩み（次の目標）

- 一門が越えた節目を、元弟子と今の弟子の最高位・優勝・関取の数・代から数える（状態を持たない純粋関数。`client/src/goals.ts`）:
  三段目 → 幕下 → 初の関取 → 幕内 → 三役 → 関取3人 → 幕内優勝 → 大関 → 横綱 → 次の代へ継ぐ
- 部屋タブの先頭に「次の目標」（名前・手がかり・進み具合のひし形）、一門タブに一覧を出す

### はじめての人向けの案内

- 部屋タブの先頭に「親方の手引き」: 稽古の方針 → 本場所へ → 取組を見る → 入門希望者を受け入れる → 帳簿を見る、の5手順。済んだものに印（✓と取り消し線）がつく。閉じられる。12場所を過ぎるか全部済んだら出ない
- 各タブを初めて開いたとき、そのタブで何をするかを1行で出す（「わかった」で消える）
- 進み具合はユーザー設定（`guide`。セーブとは別。設定版3）に持つ。済んだかどうかは、日誌・場所の数からも判定する（`client/src/guide.ts`）

### 場所の間の出来事

- 場所前に、選択肢つきの出来事が起きることがある（52種類: 後援会・タニマチ／稽古・成長／弟子の暮らし／経営／協会・一門・地域／スカウト／けが・医療）
- 誰の話か（条件に合う弟子から1人）・起きる時期（正月・節分・猛暑・夏合宿・地方場所の宿舎など）・部屋の様子（関取がいる・お金に余裕があるなど）で起きるものが変わる。同じ出来事は12場所のあいだ続かない
- 選ぶとすぐに効果が出る。確率で結果が分かれる選択肢もあり、結果は画面と日誌に出る。窓で1件ずつ聞く（任せて返事をしないまま進めると最後の選択肢になる）。効果の大きさは推定の調整値（`balance/happenings.ts`）

### スカウト回り

- 親方が新弟子を探しに出向く（1つの場所に1回。場所前の1週を使う。部屋の口座から払う）。会えた子は入門希望者に加わる（受け入れるかは別に決める。ライバルの取り合いも起きる）
- 行き先: 中学の全国大会・高校の全国大会（秋場所の前だけ）・学生相撲の全国大会（初場所の前だけ）・地方の噂（いつでも。会えないこともある）・海外（外国出身が1人。部屋に外国出身がいれば行けない）
- 経歴が決まり、素質が少し上乗せされる。スカウトの網（契約）で会える人数と見立ての正確さが上がる。数値は推定（`balance/scouting.ts`）

### 設備と契約（お金の使い道）

- 建物（寮の増築・稽古場の改修）は一度に払い、維持費がかかる。契約（トレーナー・スカウト）は場所ごとに払い、いつでも変えられる
- 金額はすべて推定（docs/realism.md「設備と契約」）

## 3. シミュレーション仕様

### 原則

- **完全決定論**: 同じ入力（状態・シード）なら必ず同じ結果。乱数はシード付き PRNG だけ。`Math.random()`・`Date` を使わない
- シミュレーションは純粋関数。描画・DOM・保存に依存しない
- 金額・定員・制度の数値は `sim/src/balance/` に集め、実際の値には出典（`docs/realism.md` の項目）をコメントで添える。
  推定の値（実際の資料がないもの）は「推定」と書く
- 乱数のシードは、ゲームのシードから用途ごとに派生させる（稽古・取組・新弟子・引退・家訓の候補）

### 力士

- 能力: 押し・四つ・技（それぞれ 0〜100）、身長、体重、気力（場所ごとの調子）
- 隠れた値: 素質（伸びの上限と速さ。壁を破ると上がる）、ピークの年齢、けがのしやすさ
- 型: 3つの能力のうち一番高いもの
- 疲労とけが: 稽古で疲労がたまり、疲労が高いとけがをしやすい。けがの間は休場（不戦敗）。公傷制度はない（実際に廃止されている）
- けがの部位（膝・足首・肩・肘・腰・胸・首・指。左右つき）と全治が付く（乱数は別の流れ）。自分の弟子の全治2場所以上のけがは、治療の方針を聞く:
  手術（1場所長く休み、強行出場できないが、古傷になりにくい）か保存療法（返事がなければこちら。古傷になりやすい）。
  治ったけがは確率で古傷として残り、けがのしやすさ・同じ部位の再発・引退の考えやすさが上がる（`balance/injury.ts`・`career/injury.ts`。数値は推定）
- 記録: 持ち給金、各地位の在位場所数、三賞・金星・優勝（年寄名跡の資格と力士褒賞金の計算に使う）
- 個性: 1人に0〜2個（稽古熱心・稽古嫌い・本場所に強い・稽古場横綱・頑丈・けがしがち・大食漢・人気者・繊細・研究熱心・冷静）。ID・素質・身長から決まり、乱数を使わない（`balance/traits.ts`・`career/traits.ts`）。稽古の伸び・疲れ・場所の調子・けが・体重・懸賞・引退・出来事の当人選びに効く。自分の弟子は番付に載って2場所で分かる
- 得意技: 決まり手ごとの白星を数え、5勝以上で白星の2割以上の決まり手が得意技になる。得意技は決まりやすい

### 取組

- 強さ = 能力（型の相性を加味）＋ 体重差の補正 ＋ 気力
- 型の相性（三すくみ）: 押し > 技 > 四つ > 押し
- 勝つ確率は強さの差から決め（ロジスティック関数）、シード付き乱数で勝敗を決める
- 決まり手は協会の82手と非技5つ（`balance/kimarite.ts`）。勝った側の型・格下の逆転か・体重で重みを変えて選ぶ（見せるための情報。勝敗には影響しない。乱数は1回だけ使う）
- 取組の演出: 決まり手と両者の型から、立ち合い → 攻防 → 決着の流れと実況（行司の掛け声つき）を純粋関数で作る（`client/src/playback/boutScript.ts`）。同じ取組なら同じ流れ。
  舞台はドット絵（客席・土俵・吊り屋根・行司・2人の力士。仕切り → 押し合い → 決着、当たった瞬間の火花と揺れ、土けむり、歓声。`playback/boutStage.ts`・`ui/BoutStagePixel.tsx`）
- 取組の組み方: 同じ地位の近い枚数どうし。同じ部屋どうしは当たらない（実際の規則）。関取の段が休場で奇数になり相手がいない日は、休場した関取との不戦勝・不戦敗にする

### 番付

- 地位: 横綱・大関・関脇・小結・前頭（ここまで幕内）・十両・幕下・三段目・序二段・序ノ口
- 定員（`balance/banzuke.ts`）: 幕内 42・十両 28・幕下 120（60枚）・三段目 180（90枚）。序二段・序ノ口は人数で変わる
- 番付編成は、勝ち越し・負け越しの数で動かし、定員に合わせて並べ直す（実際の編成会議の目安を簡略化する）
- 十両昇進: 幕下15枚目以内の全勝は必ず十両へ。ほかは幕下5枚目以内の勝ち越しだけが候補（空いた枠まで）。16枚目より下は全勝でも上がらない。候補が足りなければ十両が残る。上がった幕下は十両の下に置く（docs/realism.md「十両昇進の目安」）
- 大関の昇進: 三役で直近3場所の勝ち星の合計がおよそ33勝（目安）。大関は2場所続けて負け越すと陥落（カド番）
- 横綱の昇進: 大関で2場所連続優勝、またはそれに準ずる成績。横綱は陥落せず、成績が続かなければ引退する

### お金（実際の金額。出典は `docs/realism.md`）

- 部屋（親方）に入るもの
  - 協会の補助: 力士養成費（幕下以下1人あたり月7万円）・相撲部屋維持費（1人あたり場所ごと 11.5万円）・稽古場維持費（1人あたり場所ごと 4.5万円）
  - 養成奨励金（関取を育てた師匠へ。年額 十両 114万〜横綱 276万円）
  - 後援会・タニマチ（推定。`balance/koenkai.ts`）: 個人会員・法人会員の年会費（会員数は名声・関取・三役で目安が決まり、毎場所そこへ近づく）と、
    名前つきのタニマチのご祝儀（関係 0〜100 で額が変わる。ひいきの力士の勝ち越し・昇進で上がり、放っておくと冷え、冷えきると離れる。挨拶回りで上がる）。
    千秋楽パーティーの規模（開かない・身内で・ホテルで盛大に）で、費用・会員の増え方・関係・名声が変わる
  - 親方本人の給与（年寄 月 78.4万円など）は個人の収入として別に持ち、部屋の赤字を埋めるのに使える
- 部屋から出ていくもの（推定。実際の内訳の資料が少ない）
  - 食費（ちゃんこ）・光熱費・部屋の建物の費用・マネージャーなどの人件費・巡業や遠征の費用
- 力士本人に入るもの（部屋の会計とは別。力士の人気と生活の描写に使う）
  - 関取の月給（横綱 330万・大関 275万・三役 200万・幕内 155万・十両 120万円）
  - 幕下以下の場所手当（幕下 18万・三段目 12万・序二段 9.5万・序ノ口 8.2万円）と勝星金・勝ち越し金
  - 力士褒賞金（持ち給金 × 4000。持ち給金は勝ち越し・金星・優勝で増え、減らない）
  - 懸賞金（1本 7万円。協会の手数料 1万円、力士 6万円 = 土俵で受け取る袋 1万円 ＋ 口座への振り込み 5万円）、優勝賞金・三賞
- 部屋の所持金がマイナスで場所を終えると、親方の個人資金から補う。それも尽きたら部屋は閉鎖（一門の系譜の危機）
- 親方の行動で払うお金（スカウト回り・胸を借りる・出稽古・建物）は部屋の口座から払い、足りない分は親方の貯金から自動で出す（`sim/src/money/pay.ts`。決める前に「口座で足りない◯は親方の貯金から」と出す）

### 経営の見え方（報酬と罰）

- 場所前に「この場所の見込み」（部屋の口座・親方の貯金の動き）を出し、減っていくなら「このままだと あと◯場所でお金が尽きる」（`sim/src/money/projection.ts` の projectLedger。場所の精算と同じ式に今の部屋を入れた目安）
- 人数の経営: 部屋の口座が赤字なら「黒字まで弟子あと◯人」（幕下以下の弟子1人で動く口座の額から。部屋の定員を超えるなら出さない。`breakEvenHeads`・`headGain`）。入門希望者には「口座 +◯/場所」を添える（スカウト回りで弟子を増やすことが、口座を立て直す手になる）
- 十両が目標の弟子には「関取なら口座 +◯/場所」（養成奨励金・養成費・関取の費用・後援会の伸びを数える。関取を出すと部屋の口座が増える向きにしてある）
- 場所の結果に「報酬と罰」: 名声・タニマチの関係（ひいきの勝ち越し・昇進・負け越し・顔を出さない）・タニマチの出入り・関取の誕生と陥落・新しいけが・見込みとの差を、原因つきで並べる（報酬が先、罰が後。`client/src/rewards.ts`）

## 5. 実装ルール

- 文言は i18n ファイル（`client/src/i18n/ja.json`・`en.json`）に置く。既定は日本語
- `sim` は必ずテストを書く（決定論・各ルールの挙動・終わること）
- 実際の値を変えるとき・新しく調べたときは `docs/realism.md` を更新する（調べた日付と出典の URL）
- セーブデータはバージョン番号を持たせ、上げたら変換とテストを足す
- 状態は色だけで伝えない。本文のコントラスト比 4.5:1 以上、スマホの操作領域は 44px 以上
- 絵と色は `docs/art-style.md` に従う。色は `client/src/art/palette.ts` の1か所に置く
- 画面は昔のゲーム風（`client/src/art/retro.css`）: ドットのフォント・紺の地・角ばった太い枠のウィンドウ・題字の帯・選んだ項目を反転して ▶ を付けるタブとボタン。角は丸めない・字は太らせない
- 説明（注記・手引き・タブの案内・長い補足）は既定で出さない。上の帯のメニューの「説明」で出す・隠す（ユーザー設定 `help`。設定版4）。選ぶのに要る1行の効果だけは常に出す
- 上の帯は、場所・部屋・お金と「メニュー」（音・説明・言語・やめる）だけにする
- 部屋タブは1画面に収める: 「次の目標」（1行）→ 箱庭 → 場所前のコマンド窓（広い画面では箱庭とコマンド窓を横に並べる）。スマホ（390×844）でスクロールせずにコマンドまで見える。
  場所前の週が残っている間、下の帯の主ボタンは「あと◯週」で、押すと場所前のコマンドへ移る
  - コマンド窓: 題字の帯（週・「残りはいつも通り」・4週の印）→ 見込み（2行）→ 1行の知らせ（指しているコマンドの効果、なければ先週の結果）→ コマンド（2列）。
    相手選び・確かめはコマンドと同じ場所に出し、「もどる」で戻る
  - 狭い画面では、上の帯を2行（場所と部屋・メニューの「≡」／お金）に詰め、箱庭は稽古場から出す（外観との切り替えは絵に重ねる）
- 弟子タブ: 1人1行の一覧（地位・名前・壁やけがの札・型と方針・近い目標・疲れ）。押すと弟子のカード（稽古の方針・量・けがの扱い）を窓で開く
- 返事が要るもの（引退の申し出 → けがの治療の方針 → 場所の間の出来事 → 理事選挙 → 独立の申し出 → 入門希望者を1人ずつ）は、部屋の画面に並べず、1件ずつ窓で出す（`ui/EventDialogs.tsx`）。決めないと閉じない
- ダイアログ（`client/src/dialogs.ts`）: 開くと中へフォーカスを移し、Tab は中だけを回り、Esc は閉じるボタン（`data-dismiss`）を押す。開いている間は後ろをスクロールさせない。閉じたら元の場所へフォーカスを戻す。決めないと進めないダイアログには data-dismiss を付けない
- 画面のフォント（DotGothic16・OFL）は使う字だけに絞って同梱する。i18n の文言や名前の字を変えたら `client/build/subset-font.mjs` を実行し直す（収録漏れはテストで分かる）
- 絵を変えたら `client/build/gallery.tsx` で一覧を書き出して確かめる
- 部屋の全景の絵（スプライト）は `docs/sprites/spec.md` の決まりで作り、`client/build/import-sprites.py` でドット絵に仕上げて取り込む（背景マゼンタ・斜め上から・正面は左下・色は palette.ts に寄せる）。一覧の正本は `client/sprites/catalog.json`。生成AIで作った絵は `docs/assets.md` に記録する
- 部屋タブの先頭に部屋の箱庭（`client/src/art/hakoniwa/`）: アイソメトリックのマス目（1マス 32×16）に地面・塀・敷石を描き、建物と小物を足元のマスで置いて、奥から順に1枚のキャンバスへ描いてから拡大する（ドットの大きさがそろう）。外観（敷地: 寮〔増築の段〕・母屋・ちゃんこ場・門・治療院〔トレーナー契約〕・井戸・松・季節の木〔場所の季節。絵のある季節だけ〕・つくばい・灯籠・庭石・名札掛け・提灯・関取の幟〔四股名を重ねる〕）と稽古場（改修2段目で器具、3段目で今どきの稽古場）を切り替える。建物や物を押すと、その画面（帳簿・ちゃんこと部屋の人・弟子・スカウト・番付・稽古の方針）へ行く。取り込んでいない絵は出さない
- 箱庭の人（`art/hakoniwa/people.ts`・`actors.ts`）: 人はコードで描くドット絵（30×36。まわしの色・髷かざんばら・体つき・肌の色）。弟子は稽古の方針どおりに動く
  （稽古場: 申し合い〔2人そろったとき〕・鉄砲・すり足・四股・見取り。外観: けが人は寮の縁側で布団・休養は母屋の縁側・番付の下の2人は掃除・ちゃんこ番・入りきらない弟子は庭で四股）。
  配置は乱数を使わない純粋関数。動きは拍（0.42秒）で2コマ、動きを減らす設定では止める。季節のもの（花びら・落ち葉・雪）とちゃんこ場の湯気も描く。
  人と物の前後は足元のマスで決める（門や幟の奥にいる人は隠れる）
- 顔の絵（弟子・入門希望者・親方・歴代力士・見せ場）はコードで描くドット絵（`art/pixel/portrait.ts`。胸像と全身）。表紙の絵は春の部屋の箱庭（`ui/TitleScene.tsx`）
- 部屋の中（`art/hakoniwa/actors.ts` の ROOMS・roomCast）: 箱庭の切り替えに「部屋の中」。◀▶で居間・大部屋・厨房・風呂と洗濯場・物干し場・玄関と事務室・応接間・治療室（トレーナーの契約があるとき）・トレーニング室（稽古場の改修2段目から）・中庭・駐車場と物置を見る（2部屋の断面の1枚絵）。
  弟子は外観と同じ割り振りで部屋にいる（けが人は治療室の施術台〔あれば〕・大部屋の布団・休養は居間の座卓・番付の下から掃除番は中庭・ちゃんこ番は厨房・親方は事務室の囲炉裏）。稽古場は1枚絵（keikoba_classic）があればそれを使う
- 返事が要るものの窓には、話に合う部屋の中の絵を挿絵に出す（`client/src/eventScene.ts`。出来事の種類と中身で決める）
- 箱庭の弟子を押すと話しかけられる: 一言（けが・疲れ・先場所の成績・地位・個性・方針から、場所ごとに決まる。`client/src/voice.ts`）・疲れ・稽古の方針と量。
  狭い画面では外観を 640px より小さくせず、横に動かして見る
- バランスの調整は自動プレイの結果を根拠に行い、記録する
- 大きな変更の前には計画を示してから着手する

4. **広げる**: 系譜図の画像の共有・ライバルの部屋（入った）
