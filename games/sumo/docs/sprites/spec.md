# 部屋の全景の絵（スプライト）仕様書

部屋タブに「斜め上から見た相撲部屋の全景」を出すための絵の決まり。絵は画像生成AI（Gemini の Nano Banana）で作り、
`client/build/import-sprites.py` でドット絵に仕上げてゲームに取り込む。プロンプトは [prompts.md](prompts.md)。

素材の一覧の正本は `client/sprites/catalog.json`（この文書の表も、そこから作った）。

## 1. 絵柄

- **錦絵（浮世絵）をデフォルメした、ドット絵ふうの絵**。リアルにしない
- 平たい色面と、墨の輪郭線。グラデーション・光沢・写真のような質感は入れない
- 陰は1段だけ（明るい面と暗い面）。影は足元に小さく、背景には落とさない
- 人は2〜2.5頭身。丸い顔、点か短い線の目、ほおに薄い紅。体はふくよかで丸い
- 建物は和風の木造（瓦屋根・漆喰の壁・木の柱・障子・暖簾）。形で用途が分かるように少し大げさにする
- 文字（看板・暖簾の字・ロゴ）は描かない。看板の名前はゲームが重ねて書く

## 2. 角度と向き

- **アイソメトリック（2:1）**。斜め上（およそ30°）から見下ろす
- **建物の正面（入口）は左下を向き、側面が右下に見える**。すべての絵でそろえる
- 光は左上から。右下の面が暗い
- 人の向き: 1枚目は左下を向く。右下向きはゲームで左右反転して作る（描かなくてよい）
- 地面の1マス = 32×16 ドット（ひし形）。人の背丈は約1.3マス

## 4. 生成の決まり（これを守ると取り込みが崩れない）

1. **背景はマゼンタ（`#FF00FF`）の一色**。模様・床・地面・影を背景に描かない
   （くすんだ赤紫など一色の背景でも取り込めるが、絵の赤い所と近い色だと縁が欠けることがある。できるだけ純粋なマゼンタで）
2. 1枚に描くのは1つの素材。**コマが2つ以上の素材は、同じ大きさで横一列に並べ、間を十分あける**（重ねない・つなげない）
3. 素材は画面いっぱいに大きく、端で切れないように
4. 文字・枠・署名・透かしを入れない
5. **最初に「見本」を1枚作り、以後はすべてその見本を参照画像として添えて生成する**（絵柄・線の太さ・色・角度をそろえるため）
6. 縦横比は仕上がりの形に近いものを選ぶ（建物は 1:1 か 4:3、人を並べたものは 16:9 や 21:9 など横長）

## 5. 人の決まり

- **稽古のまわし: 幕下以下は黒、関取は白**（実際の稽古場の決まり。`variants` の `kuro`・`shiro`）
- 髪はちょんまげ（大銀杏は本場所だけなので描かない）。裸足
- けが人は布団に横になり、腕か頭に白い包帯
- 親方は着物（藍か墨色）、おかみさんは落ち着いた色の着物
- 同じ姿勢の2コマは、ほんの少しだけ違う（足を上げる／下ろす など）。体の大きさと位置は変えない

## 7. ファイル名と置き場所

- 生成した画像は `client/sprites/raw/` に置く（png・webp・jpg のどれでもよい）
- ファイル名は ID のまま: `pine.png`。種類があるものは `rikishi_shiko__kuro.png` のように `__種類` を付ける
- 取り込み: リポジトリ直下で `python3 games/sumo/client/build/import-sprites.py`（指定した ID だけなら後ろに並べる）
  - 仕上がりは `client/src/assets/sprites/`、一覧は `client/src/art/sprites/manifest.json`
  - 取り込みの手順: 背景を抜く → コマを切り分ける → 余白を切って仕上がりの大きさに縮める（足元を下の中央に） → パレットに寄せる → 人と小物は墨の縁取り
- 生のファイル（raw）は大きいので git に入れない（`.gitignore`）。仕上がりの PNG だけを入れる

## 8. 確かめ方（1枚ごと）

- [ ] 背景がマゼンタ一色で、影や地面が背景に描かれていない
- [ ] 角度が見本と同じ（正面が左下・側面が右下）
- [ ] 線の太さ・色合い・頭身が見本と同じ
- [ ] コマの数が合っていて、横に並び、くっついていない
- [ ] 文字・透かしがない
- [ ] 取り込んだあと、ゲームの画面で他の絵と並べて浮いていない

## 9. 権利と記録

- 生成AIで作った絵は `docs/assets.md` の表に「生成AI（Gemini・モデル名）」として記録する。人が描き直したら更新する
- 販売の前に、使ったモデルの利用規約（商用利用・透かし）を確かめる。Steam で出すときは生成AIの使用を申告する
- 実在の力士・部屋・団体の名前やロゴ、他の作品の絵を似せて描かせない（参考画像も「雰囲気の参考」にとどめ、写させない）
