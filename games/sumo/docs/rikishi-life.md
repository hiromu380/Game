# 力士の暮らし・しきたり・制度（調査メモ）

2026-11-16 調べ。ゲームで「遊ぶと相撲に詳しくなる」ための下調べ。実装した値は `docs/realism.md` に移す。

確かさの印: **［公］** 協会の発表・報道で確かめた　**［報］** 報道・元力士の談話（部屋により違う）　**［ブ］** 解説ブログ・まとめ（要確認）

## 1. 相撲部屋の一日

| 時刻（目安） | すること                                                                           | 誰が                                                       |
| ------------ | ---------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| 5〜6時       | 起床・稽古場へ。**朝食はとらない**（空腹で稽古）［報］                             | 番付の下から先に起きる                                     |
| 6〜10時ごろ  | 朝稽古（約2時間半〜4時間）。**番付の下の者から土俵に上がり、関取は最後**［報］     | 全員                                                       |
| 10〜11時     | 風呂（番付の上から）［報］                                                         |                                                            |
| 11〜12時     | ちゃんこ（その日最初の食事）。**親方・関取が先に食べ、若い者は給仕してから**［報］ | 全員                                                       |
| 12〜15時     | 掃除・昼寝。新弟子は兄弟子の使い走り・買い出し［報］                               | 若い衆は雑用が多い                                         |
| 15〜18時     | 自由時間・ちゃんこの支度（ちゃんこ番は幕下以下の持ち回り。有望な者は免除も）［報］ |                                                            |
| 18時〜       | 夕食・自由時間・門限［報］                                                         | 外出は関取は自由、幕下以下は許可制・回数制限の部屋も［ブ］ |

- 親方が座って「座っていい」と言うまで、兄弟子も座れない（元小結の談話）［報］
- 稽古中・食事中のスマホは禁止の部屋が多い［ブ］。**支度部屋への携帯電話の持ち込みは禁止**（八百長防止で決まり）［報］

## 2. 稽古の種類

- 基本: 四股・すり足・鉄砲・股割り（体を目覚めさせる。毎日）［報］
- 申し合い: 勝った者が土俵に残り、次の相手を指名して続ける［報］
- 三番稽古: 力の近い2人が相手を替えずに何番も取る［報］
- ぶつかり稽古: 受け手の胸にぶつかって土俵際まで押し、最後は転がって受け身。「かわいがり」とも呼ばれ、暴力問題とも結びつけて語られる［報］

## 3. 番付で変わること（番付社会）

| 番付           | 髪                               | 服・履物                                                                   | 暮らし                                           |
| -------------- | -------------------------------- | -------------------------------------------------------------------------- | ------------------------------------------------ |
| 序ノ口・序二段 | ちょんまげ（伸びるまでざんばら） | 部屋の仕着せの浴衣・素足に下駄［ブ］                                       | 大部屋。雑用・付け人                             |
| 三段目         | ちょんまげ                       | 雪駄が履ける。羽織が着られる［ブ］                                         | 大部屋                                           |
| 幕下           | ちょんまげ                       | 外套（コート）・襟巻・博多帯・足袋［ブ］。自室にテレビを置ける部屋も［報］ | 大部屋。関取の稽古相手                           |
| 十両           | **大銀杏**（取組の時）           | 紋付羽織袴。白足袋［ブ］。稽古まわしが**白**、取組は**絹の締込**［報］     | **個室・月給・付け人・化粧まわし・明け荷**［報］ |
| 幕内           | 大銀杏                           | 四股名入りの浴衣を作れる・染め抜きの着物［ブ］                             |                                                  |

- いちばん大きな差は十両と幕下の間［報］。幕下以下は月給がなく、場所手当（＝小遣い程度）だけ。衣食住は部屋が持つ［報］
- 十両に上がると: 化粧まわし（後援会・郷土などが贈ることが多い。100万〜数百万円、納期半年〜1年）・**明け荷は同期生が贈る習わし**・力士補助費（年3回、協会から）［報］
- 元関脇の談話: 十両昇進時、手元10万円で化粧まわし代300万円を工面した［報］

## 4. 付け人

- 幕下以下の力士が、関取の身の回りを世話する。人数は **十両 2〜3人・幕内 3〜4人・横綱 8〜10人**（10人以上のことも）［ブ・報］
- 仕事: 明け荷の準備と運搬・締込の着け外し・下がり作り・化粧まわしの管理・塩や力水の用意・風呂の支度と背中を流す・洗濯・買い物・食事の給仕（関取が食べてから自分が食べる）［ブ］
- 若い付け人は雑用、三段目・幕下になると関取の稽古相手［ブ］
- 2018年の再発防止策で「関取が付け人を酒席などに夜遅くまで連れ回さない」よう指導［報］

## 5. 入門からデビューまで

1. 部屋に入門 → 新弟子検査（体格基準 167cm・67kg、満たなければ運動能力検査。内臓検査あり）［報］
2. 前相撲（番付外）: 1994年3月場所からは、勝てなくても1番取れば出世できる［ブ］。勝ち抜けた順に一番出世・二番出世…
3. **新序出世披露**（通常は中日）: まだ化粧まわしを持たない新弟子は、**師匠や部屋の関取から借りた化粧まわし**で土俵に上がり、四股名を紹介される［ブ（国会図書館レファレンスあり）］
4. 翌場所、序ノ口として番付に四股名が載る
5. 相撲教習所（両国国技館内）で**6か月**: 四股などの実技（親方と幕下力士が教える）・相撲史・書道・相撲甚句（2026年6月に9年ぶり再開）［報］
6. 秋場所などの千秋楽には、新弟子が「出世力士手打式」「神送りの儀」に加わる［報］

- 新弟子検査の受検者は減っている（春場所: 2021年35人→2024年27人→2025年34人）。高校・大学の相撲部出身の割合が増え、アマチュアとのつながりのない親方ほど弟子集めが難しい［報］
- 番付に載る力士は約590人（ある年の春場所 588人）［報］

## 6. 一年の流れ（場所の前後）

- 番付発表: 初日の約2週間前（例: 2026年春場所 2月24日発表・3月8日初日）［公］
- 番付編成会議: 場所後3日以内。大関・横綱・十両の昇進をここで決めて発表［報］
- 横綱審議委員会の稽古総見: 場所前に国技館で。夏場所前は一般公開［報］
- 土俵祭: 初日の前日、土俵に神様を迎える。千秋楽に神送り［報］
- 新弟子検査: 場所前（例: 2027年は7月7日と発表済み）［公］
- 巡業: 春（春場所後、伊勢神宮奉納から）・夏・秋・冬。稽古・子どもとの稽古・初切（禁じ手を面白く見せる）・髪結いの実演・握手会［報］
- 場所の間: 巡業・トーナメント・慈善相撲・引退相撲［報］

## 7. 部屋の人たち

- **おかみさん**: 経営（収支・後援会名簿）・後援会などの渉外・弟子の心の支え。前職はさまざま（元CA・医師・アナウンサーなど）［報（早稲田大の研究）］
- **行司・呼出・床山**: どれも相撲部屋に所属して協会員になる。行司は取組の裁き以外に、場内放送・取組表の作成・巡業の手配・部屋の雑務（仕事の8割は裏方とも）［報］
- 若者頭・世話人・マネージャー（ゲームに一部入っている）

## 8. 決まりごと・規律

- **現役力士は車・バイクの運転禁止**（協会の内規。免許は取れる。引退後は可）［報］
- 支度部屋への携帯電話持ち込み禁止［報］
- 暴力: 2018年10月「暴力決別宣言」。暴力の全面禁止・師匠による部屋内暴力の根絶・新弟子／兄弟子／関取の3段階の研修・コンプライアンス委員会［報］
  - 師匠の暴力は重く処分（2020年 2階級降格と部屋の閉鎖。2026年 元横綱の親方が2階級降格）。宣言の後も起きている［報］

## 9. 横綱まわりと千秋楽（2026-11-16 追記）

- 稽古総見は東京場所（1・5・9月）の前。基本、幕内は平幕中位以上の参加が義務づけられ、けがなどなら欠席できる［報］
- 太刀持ちは原則幕内で、できれば横綱と同じ部屋から、いなければ同じ一門の別の部屋から［ブ（Wikipedia）］。露払いも同じ形と言われる
- 千秋楽の表彰式の後、その場所に出世した新弟子が土俵に上がり、手打ち（出世力士手打式）をして行司を胴上げする（神送りの儀）［報］
- 弓取式は幕下以下の力士が務める。横綱と同じ部屋や一門の力士が多いと言われる（今回は出典を確かめられていない）

## 10. まだ確かめていないこと

- 結婚と部屋の外での暮らし（関取は結婚すると部屋の外に住めることが多い、と言われるが出典が弱い）
- 幕下以下の外出・門限の時刻、小遣いの額
- 雨の日の傘・履物の決まり
- 番付ごとの服装の細部（解説サイトで食い違いがある。協会の文書は見つからなかった）

## 優勝・全勝・金星・年間最多勝（2026-11-26 調べ。相撲の手帖の言葉）

- 優勝: 各段で勝ち星がいちばん多い力士。同点なら千秋楽に優勝決定戦を行う（幕下で9人による決定戦の例: https://www.daily.co.jp/general/2021/01/24/0014028405.shtml ）。幕内の優勝者は賜杯を手にする（ https://www.daily.co.jp/general/2020/01/26/0013064732.shtml ）
- 全勝: その場所の取組（関取15番・幕下以下7番）にすべて勝つこと
- 金星: 平幕が横綱に勝つこと。持ち給金が10円上がる（realism.md「持ち給金」）
- 年間最多勝: 1年6場所の勝ち星の合計がいちばん多い力士として記録に残る（白鵬の86勝が最多、朝乃山は2019年に小結以下で初めて獲得: https://spaia.jp/column/sumo/15644 ・ https://www.daily.co.jp/sumo/2015/11/20/0008581461.shtml ）
