# 素材と権利（一門）

| 対象                                       | 出所・制作方法                                                               | ライセンス・扱い                                                                       | 生成AI画像 |
| ------------------------------------------ | ---------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- | ---------- |
| 力士・親方・行司・土俵・タイトル背景・和柄 | このリポジトリのTypeScript / SVGによる手続き造形。AIによるコード実装支援あり | 外部画像・似顔絵は不使用。プロジェクトのコードとして管理                               | 不使用     |
| Kaisei Tokumin ExtraBold                   | Google Fonts / FONTWORKS。既存のフォントを追加文言に合わせてサブセット再生成 | SIL Open Font License 1.1。同梱 `client/src/assets/fonts/OFL.txt`。参照は既存のCSS経由 | 不使用     |
| Three.js                                   | three 0.180系。実際の解決版は依存ロック差分を参照                            | MIT。ライブラリであり画像素材ではない                                                  | 不使用     |
| 引き継ぎの3案比較画像                      | 依頼者から提供されたAI生成の参考図                                           | A案の方向性確認のみ。ゲーム・ビルド・配布物に画像を同梱しない                          | 参考図のみ |
| 肖像キャッシュ                             | 実行時にモデルからCanvasでWebP / PNGを生成                                   | 一時的な表示用。外部素材の追加なし                                                     | 不使用     |

新しい配布画像ファイルは追加していない。新規の画像素材を採用する場合は、アセットマニフェスト経由で参照し、この表へ商用利用条件と生成AIの利用有無を追記する。
