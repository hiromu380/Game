# ゲームの質を上げる計画（2026-10-30）

絵を並べただけで遊びとつながっていない、という指摘から。5つの柱をすべて進める。

## 0. 箱庭の土台（済み）

- マス目（1マス 32×16）に地面・塀・敷石を描き、建物と小物を足元で置く。1枚のキャンバスに描いてから拡大する
- 建物・物を押すと、その画面へ（帳簿・ちゃんこと部屋の人・弟子・スカウト・番付・稽古の方針）

## 1. 部屋を箱庭にして、画面の主役にする

- 弟子が箱庭にいる（方針どおりの稽古・けが人は布団・新弟子はざんばら・関取は白まわし）。押すと話しかけられる（調子・悩み・目標、方針の変更）
- 季節・場所の前後で景色が変わる（巡業中は関取がいない、場所前は張り詰める）
- 要る絵: 力士（立つ・四股・鉄砲・すり足・座る・寝る。黒・白まわし）・申し合い・親方（`docs/sprites/prompts.md` の優先 A）

## 2. 稽古を見える成長にする

- 場所の間に短い稽古の場面。申し合いの組み合わせ・出稽古を選ぶ
- 伸びとけがの危なさを頭の上に出す。稽古の量（軽め・ふつう・猛稽古）

## 3. 本場所を遊べるようにする

- 初日・中日・13日目・千秋楽で止まる。大一番に作戦（立ち合い・得意の形）
- 取組を3Dで見届ける。毎日の見出し

## 4. 弟子の物語

- 一人ひとりの目標（地元に錦・新十両・兄弟子越え）と、かなった・破れた場面
- 兄弟子・弟弟子・付け人・親の手紙・宿敵の力士。引退の一言が歩みで変わる

## 5. 代ごとの目標と節目

- 代の目標（10年で関取3人など）・節目の評価と称号・部屋の格で増えること
