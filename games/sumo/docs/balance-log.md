# バランスの記録

計測は `pnpm --filter @ichimon/sim balance -- --seeds N --basho M`（ボット2種で遊ぶ。`sim/tools/`）。

- careful: 見立ての良い入門希望者を選ぶ（弟子が12人未満のうちは広く受け入れる）・疲れたら休養・余裕があれば設備と契約
- passive: 入門希望者はみな受け入れ・方針も設備もそのまま

- 300場所の幕内優勝の4割を自分の部屋が取っていた。実際の名門でも一代で関取は十数人ほど
- 番付全体: 横綱の平均 0.6人・大関 2.0人（実際は横綱1〜2人・大関2〜3人ほど）

原因:

1. 入門希望者が多すぎた（1年に8人以上。実際は全体で年に50〜60人ほどを40余りの部屋で分ける）
2. 自分だけ素質で選べた（架空の部屋は新弟子を選ばない）
3. 稽古場・部屋付きの親方の伸びの上乗せが大きかった
4. 横綱の在位が短すぎた（2場所の負け越しで6割が引退・衰えが速い）

### 調整

- 入門希望者: 春場所の前に1〜2人、ほかの場所の前は15%の確率で1人（名声・スカウトの網で最大50%）
- 架空の部屋も新弟子を選ぶ（半分の確率で素質を2回引いて良い方）
- まれな逸材（素質 92〜100）を 1.2% 足す。名声による素質の上乗せは最大 6
- 稽古場の伸び 6% → 4%/段、部屋付きの親方の上乗せの上限 15% → 10%
- 関取になったことのない力士の引退を増やす（年に +6%、21歳から伸びない若手は +15%）
- 勝つ確率のなだらかさ k 9 → 7（力の差が勝敗に出やすく、強い力士が勝ち続ける）
- 横綱: 準ずる成績を 13勝 → 12勝（2場所の合計 27 → 26）。2場所続けて負け越しで 30%、3場所で 70% が引退
- 衰え: 年 2.2 → 1.6、加速 0.3 → 0.25

## 2026-10-30 代を重ねると強くなりすぎるのを直す

計測ツールに代ごとの集計を足した（seeds 1〜6・300場所 = 約2代）。

| 条件                                      | careful 1代目 関取 / 幕内優勝 | careful 2代目 | passive 1代目 | passive 2代目 | 最後の名声（careful） |
| ----------------------------------------- | ----------------------------- | ------------- | ------------- | ------------- | --------------------- |
| 調整前                                    | 21.0 / 5.7                    | 43.2 / 27.7   | 10.3 / 0.7    | 21.0 / 3.4    | 502                   |
| 名声・寮・家訓を絞る                      | 19.8 / 6.2                    | 33.3 / 27.0   | 8.8 / 1.2     | 20.6 / 3.0    | 230                   |
| ＋ 有望な中学生・名声の素質を絞る（採用） | 16.7 / 3.8                    | 27.4 / 17.2   | 9.3 / 1.3     | 17.6 / 3.2    | 169                   |

原因と調整:

- 名声が積み上がり、入門希望者と素質が増え続けた → 新横綱の名声 20 → 15、幕内優勝 8 → 5、名声の残り方 0.97 → 0.96/場所、春の上乗せ 2 → 1人まで、名声による素質の上乗せ 6 → 4
- 寮で 50人まで住めた → 1段 5人（最大 40人。実際の大部屋は 30〜40人ほど）
- 家訓の型の伸び 15% → 10%
- 出来事「有望な中学生の噂」の素質が高すぎた（70〜92。1代に何人も来る）→ 60〜82

- 2代目が1代目より強いのは、1代目が弟子4人から始めるため（2代目は育った部屋を継ぐ）。passive でも同じ傾向
- careful の2代目の幕内優勝 17回は、強い横綱が出たランが平均を押し上げている（名門の黄金期くらい）
- 残る課題: 大関がやや少ない（平均 1.6人）

## 2026-10-30 理事選挙・年齢の調整（seeds 1〜5・150場所）

- 自分の親方が理事長でいる時間が約4割あった（理事候補の格に「いまの役職」を足していて、一度上がると上がり続けた）。
  格を「年齢 × 0.4 + 現役の最高位 + 育てた関取 × 4 + 部屋の名声 / 12」に変え、理事長は前の期から続けて理事の親方から選ぶ。
  → 理事長でいる時間: careful 12%・passive 4%（理事は careful 28%・passive 14%）
- 幕内の平均年齢が若すぎた（26.6歳。実際は29歳前後）。ピークの年齢 25〜30 → 28〜32、衰え 1.6 → 1.2/年、加速 0.25 → 0.2、引退を考え始める年齢 30 → 31
  → 幕内の平均年齢 27.7歳・大関 1.5人・横綱 0.8人・新十両 24.4歳（実際 23.5歳）
- お金: 150場所後の合計が以前より多い（2.5〜3.5億円）。内訳は「親方の給与（役職で上がる）− 生活費」が個人の貯金にたまる分で、
  後援会は旧来の式とほぼ同じ。部屋の赤字を埋める余力が増えただけなので、ここでは直さない
- 残り: 大関・横綱はまだ実際（大関2〜3人）より少なめ。新十両の年齢がやや上がった
