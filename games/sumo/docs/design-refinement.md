# デザイン再調整（2026-10-30）

前回の3D統合版を基準に、A案の落ち着いた色面を保ちながら表紙と紙面の視覚階層を整理した。

## 変更点

- 本文用Kaisei Tokumin Regularを同梱。見出しの800と本文の400を分け、環境によって全体が太字になる状態を解消。日英文言と名前に必要な888文字を両方に収録した。
- 全面の反復和柄と太い角丸枠を抑え、藍のヘッダー、朱の印、細い罫線、余白で画面の役割を示す。選択中のタブ・稽古方針には枠と文字の変化も残した。
- 表紙に架空の三輪の紋と朱印を追加。開けた障子、山並み、暖簾、稽古場をコード製SVGで描き、共通3Dの人物を重ねた。参考画像は素材として使用していない。
- 弟子カードを名入りの肖像札に変更。PCでは二列、スマホでは一列。名前・能力・状態・稽古方針を順に並べ、操作領域44px以上を保った。
- 3Dの胴を一続きの回転体に変更。肩から腹へ重心を下げ、腕・親指・帯の折り返し・鬢の流れを加えた。俵の結束縄、幕のたるみ、山並み、架空の紋を追加し、力士を大きく見せる画角に調整。
- 接地計算では重複頂点を一度だけ除き、接地・画角の測定結果を共有。描画を間引くフレームでは頂点計算も省く。回転した人物の外形がThree.jsの全頂点測定と一致することをテストした。

## 検証

- Vitest: **16ファイル・83テスト成功**。
- TypeScript strict、ESLint、本番ビルド成功。
- 390px / 1280pxでタイトル、部屋、番付、帳簿、一門、場所の結果、取組を起動確認。
- 長い名前、けが・疲労、軽重の体型、横綱・大関、分家、英語の表示を確認。ページの横はみ出し・JavaScript例外なし。
- WebGLなし、コンテキスト喪失、3Dチャンク失敗時のSVG復旧と結果表示を確認。
- reduced-motionの静止表示、PNGへの代替、20回開閉後のGPU解放を確認。各回のジオメトリは解放後0、未使用時のGLコンテキストは0に戻った。
- 画面撮影前に遅延肖像を順に表示し、3D画像が生成されてから撮影するよう検証スクリプトを修正した。

シミュレーション、取組台本、セーブ形式、依存パッケージは変更していない。push・リモート変更・PR作成は行っていない。

## 実測の限界

ブラウザはChromium 153 / SwiftShader。幅390pxはタッチ端末のエミュレーション、1280pxはPCのエミュレーションで、実機のiOS Safari / Android Chromeや外部GPUは未検証。

造形一覧と取組を連続して生成する検証では、短い約2.8秒の取組で390px約27.6fps、1280px約18.5fpsを記録。描画呼び出し78、ジオメトリ61、トゥーン用テクスチャ1。30 / 45fpsは目標上限であり、このソフトウェア描画環境で達成を保証するものではない。前回と負荷条件も異なるため、単純な速度比較には使えない。

本文用WOFF2が約169KB増えた。3D共通チャンクは約527KBでViteの500KB警告が残る。前回の `graphics-validation.md` に記載したCI用の依存ロック適用と実機での長時間検証は引き続き必要。
