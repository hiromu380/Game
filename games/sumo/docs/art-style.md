# 絵柄の決まり（一門）

相撲絵（錦絵）を、二頭身にゆるくした絵柄。絵はすべてコードで描く SVG（生成AIの絵は使わない）。

## 線と面

- 輪郭は墨の均一な線（太さ 2.5 前後。拡大・縮小しても同じ見え方になるよう、絵ごとに viewBox を固定する）
- 塗りは平たい色面。影・グラデーションは使わない（立体感は色面の重なりで出す）
- 二頭身: 頭が大きく、体は丸い。手足は短い。ほっぺに薄い紅

## 色（`client/src/art/palette.ts` の1か所で決める）

| 名前           | 用途                               |
| -------------- | ---------------------------------- |
| 生成り・和紙   | 背景                               |
| 墨             | 線・文字                           |
| 藍             | 主の色（見出し・地位）             |
| 紅（朱）       | 大事なボタン・印・強調             |
| 黄土           | 土俵・木札                         |
| 若竹・紫・金茶 | 締め込み（関取のまわし）・分家の印 |

- 本文の文字と背景のコントラスト比は 4.5:1 以上
- 状態は色だけで伝えない（記号・文字・枠を併せる）

## 力士

- 同じ力士はいつ見ても同じ顔（力士 ID から目・眉・口・肌の色を決める）
- 体つきは体重で変わる（重いほど横に広い）
- 髪: 入門したて（6場所まで）はざんばら、その後はちょんまげ、関取は大銀杏
- まわし: 幕下以下は黒の稽古まわし、関取は部屋ごとの色の締め込みに下がり、横綱は白い綱
- けがをしていれば包帯、疲れていれば汗

## 和柄

- 青海波（背景・見出しの帯）、麻の葉（パネルの縁）、市松（タブ）。どれも薄く、文字の邪魔をしない
