# 絵柄の決まり（一門）

A案「ゆるい浮世絵を立体化」を採用する。二〜二・五頭身、墨の輪郭、落ち着いた和色、少ない段階の陰影で統一する。生成AIの参考画像は方向性の確認だけに用い、ゲームの素材には使用しない。

## 造形と色

- 力士・親方・行司・土俵はコード製の3D。経営画面は文字を中心とする和紙・木札・罫線。画像テクスチャ、金属的な反射、被写界深度、写真風の影は使用しない。
- 色は `client/src/art/palette.ts` に集約し、UIはそこから配るCSS変数を使う。
- 輪郭は背面の墨色の面。部品の大きさに対して単純に拡大せず、一定の厚みを加える。胸と腹、表情にだけ細い線を置く。
- 陰影は三段のトゥーン。静的な面は支点と色ごとに結合する。球・箱・押出しのインデックス形式を揃え、統合時に形状を欠落させない。
- 土俵は四角い台と円形の勝負俵。俵は28束を円周の接線方向に並べる。吊り屋根は反りのある押出し形状、水引幕は紫、房は白と朱。実寸の再現より画面での読み取りを優先する。

## 人物の同一性と状態

- 既存の `Look` をSVGと3Dで共有する。力士ID由来の目・眉・口・肌色を保つ。顔の組合せと輪郭、体重による胴幅で個体差を示す。
- ざんばら、ちょんまげ、大銀杏を輪郭で区別する。大銀杏は頭の上で前へ折り返し、葉先の切れ込みと放射状の筋を持つ。冠のように直立させない。
- 関取は部屋色の締め込みと下がり、横綱は白い綱。けがは包帯、疲労は汗。親方には袖・裾・合わせ襟・帯・紋を付け、年齢で髪色を変える。
- 肖像と取組は同じ `figure3d.ts` のモデル。肖像は透明背景の静止画像として再利用し、カードごとの常時WebGL描画はしない。

## 取組

- 勝敗・決まり手・台本の時刻は従来どおり。`sim/` と `playback/boutScript.ts` は変更しない。
- 東は右、西は左。人物の向きだけを内側へ向け、倒れの支点は世界の左右に保つ。すり足・腰落とし・押し手は描画の補間だけで加える。
- 2Dの点を立体へ写した際の胴の貫通は、表示上の間隔と着地点で補正する。これは物理演算や勝敗判定ではない。
- 倒れたモデルの実頂点を使って最低点を土俵面へ合わせる。行司は奥に置く。画角を人物の外形に合わせ、土俵外へ出た頭まで収める。
- 初回ロードと描画器の準備が済んでから演出時計を始める。動きを減らす設定では最終場面のみ。背景タブ復帰時は現在の姿勢を再描画する。

## 肖像・性能・復旧

- Three.jsは動的インポート。タイトルの肖像が画面に入ると3Dチャンクも取得するため、「別チャンク」は「タイトル表示後も未取得」を意味しない。
- 肖像用レンダラは共有1個。画面内と直近の肖像を一枚ずつ空き時間に生成し、64件のLRUキャッシュに保持する。中止された依頼は描画せず、未使用のレンダラは8秒後に解放する。
- 肖像はWebPを優先し、非対応環境ではブラウザのPNG出力を使う。画像化済みの肖像はGPUコンテキスト喪失後も表示できる。
- タッチ端末はDPR上限1.3・描画目標上限30fps、その他は1.5・45fps。面積の予算も設ける。これらは実機での速度保証ではない。
- 取組を閉じたらジオメトリ・材質・トゥーン用テクスチャ・レンダラ・コンテキストを解放する。React StrictModeの再初期化時は新しいCanvasを使う。
- WebGL利用不可、描画失敗、コンテキスト喪失、3Dファイルの読み込み失敗は既存SVGへ戻す。肖像の失敗時はSVGを残し、GPUの再試行に待ち時間を設ける。

## 経営画面

- 番付は墨の罫線と朱の印。広い日本語画面だけ四股名を縦書きにし、スマホ・英語では横書きにする。
- 帳簿は和帳の綴じと罫線、等幅の数字。系譜は掛け軸の木軸と接続線。師匠・分家・待機・閉鎖は文字と枠も併用する。
- 弟子カードは白い紙面と独立した肖像枠。左側を塗り分ける帯を設けない。長い名前は折り返す。
- 見出しはKaisei Tokumin、本文は端末の明朝体を優先し、同梱フォントも代替に使う。追加文言は日英i18nで管理し、フォントのサブセットを再生成する。
- 本文コントラスト比4.5:1以上。操作領域44px以上。意味は装飾画像だけに持たせず、状態は文字・記号でも示す。

## 確認方法

既存SVGのSSR一覧は `client/build/gallery.tsx`、3Dの造形一覧は開発時の `/build/review.html`。主要画面・形状・描画速度・20回開閉・SVG復旧は `client/build/verify-graphics.mjs` で再検証できる。詳しい実行方法と実測条件は `graphics-validation.md` を参照する。
