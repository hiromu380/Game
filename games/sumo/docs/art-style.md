# 絵柄の決まり（一門）

相撲絵（錦絵）を、二頭身にゆるくした絵柄。経営画面と肖像はコード製の SVG、取組はコード製のトゥーン3D（WebGL不可なら従来SVG）を使う。生成AI画像はゲームの素材にしない。

## 線と面

- 輪郭は墨の均一な線。SVG は線幅 2.5 前後（viewBox 固定）。3D はモデルの輪郭を細い墨のシルエットで表現
- 塗りは平たい色面。写実的な反射、写真風テクスチャ、被写界深度、過剰なグラデーションは避ける。3Dの影は少ない段階のトゥーンで抑える
- 二頭身: 頭が大きく、体は丸い。手足は短い。ほっぺに薄い紅
- A案: 「手描きの浮世絵がそのまま立体になったような世界」。艶のある量産フィギュア風、過剰なディテールは避ける

## 色（`client/src/art/palette.ts` の1か所で決める）

| 名前           | 用途                               |
| -------------- | ---------------------------------- |
| 生成り・和紙   | 背景                               |
| 墨             | 線・文字                           |
| 藍             | 主の色（見出し・地位）             |
| 紅（朱）       | 大事なボタン・印・強調             |
| 黄土           | 土俵・木札                         |
| 若竹・紫・金茶 | 締め込み（関取のまわし）・分家の印 |

- 本文の文字と背景のコントラスト比は 4.5:1 以上
- 状態は色だけで伝えない（記号・文字・枠を併せる）

## 力士

- 同じ力士はいつ見ても同じ顔（力士 ID から目・眉・口・肌の色を決める）
- 体つきは体重で変わる（重いほど横に広い）
- 髪: 入門したて（6場所まで）はざんばら、その後はちょんまげ、関取は大銀杏。大銀杏は先が扇状に広がる銀杏の葉型
- まわし: 幕下以下は黒の稽古まわし、関取は部屋ごとの色の締め込みに下がり、横綱は白い綱
- けがをしていれば包帯、疲れていれば汗

## 取組の3D表示

- SVGの `Look` と `playback/boutScript.ts` を変換して3Dにする。シミュレーションには触れない
- 斜め前方から見る固定カメラ。東は右、西は左で統一。行司は土俵奥に置き、倒れた力士と重ならないようにする
- 低ポリゴン・マットな色・手描き調の輪郭。色は `palette.ts` の値だけを使う
- 取組時のみ Three.js を遅延読み込みし、描画は可能な限り既存の時刻更新で動かす。WebGLが使えなければSVGを表示する
- `prefers-reduced-motion` では既存の「最後の場面だけを表示する」挙動を維持する

## 和柄

- 青海波（背景・見出しの帯）、麻の葉（パネルの縁）、市松（タブ）。どれも薄く、文字の邪魔をしない

## 文字

- 見出し・四股名・地位: Kaisei Tokumin（SIL Open Font License 1.1。使う文字だけに絞って同梱）
- 本文: 端末の明朝体

## 3D肖像とタイトル画面（第2段階）

- 取組で用いる造形関数を `client/src/art/three/figure3d.ts` に集約する。肖像も同じ形・墨線・マットな色面を使う
- 力士カード、入門希望者、親方、系譜図は、表示領域に入った時点で3Dモデルから1枚のPNGデータURLを生成しキャッシュする。リアルタイムで各肖像を描画し続けない
- タイトル画面は従来のコード製SVG（のれん、板間、壁）と立体人物の静止画を重ねる。人物の写実性より意匠の一貫性を優先する
- WebGLが利用できない端末、初期ロード中、描画に失敗したときは従来のSVG人物が表示される
- 同じ力士の顔は `rikishiLook` / `oyakataLook` が決定し、勝敗ロジックに描画の処理を混ぜない
- 画像キャッシュは最大96種類。単一のWebGL描画器を共有し、無駄なGPUコンテキストを作らない


## 番付・帳簿・系譜の装い（第3段階）

- 番付表は紙の枠、墨の罫線、朱の印影、PC幅でのみ縦書きの四股名を使用。スマホは読みやすい横書きのまま
- 帳簿は和帳の二重線と黄土色の集計行。金額は元の数値表示を維持し、背景の装飾で誤読させない
- 系譜図は掛け軸の上下の木軸と縁を表現。元のDOM・キーボード操作・状態表示は維持する
- UIの装飾は `client/src/art/paper-ui.css` に分離。色の実値は足さず、`palette.ts` のCSS変数のみ使用する

## 立体土俵の細部（第3段階）

- 四角い盛り土に円形の勝負俵を重ねる。勝負俵の細かな束は決定論の純粋関数で等間隔に配置する
- 行司は土俵の奥の正面へ下げる。3Dは現実の奥行きで遮蔽し、倒れた力士と同じ面に重ねない
- 取組の足元は弱い単色の楕円だけで接地を補助する。光沢・写真風の床影・パーティクルは使わない
