# Chain Factory（仮）

工場フロアにパーツを置き、スイッチを1回押すだけで連鎖が走る「連鎖ビルダー × ノルマ上昇型ローグライク」。
設計書は [CLAUDE.md](./CLAUDE.md) を参照。現在は **フェーズ1: コア検証** の段階。

## 必要なもの

- Node.js 22.12 以上
- pnpm 10 以上（`corepack enable` で有効化できます）

## よく使うコマンド

| コマンド                    | 内容                                                    |
| --------------------------- | ------------------------------------------------------- |
| `pnpm install`              | 依存関係のインストール                                  |
| `pnpm dev`                  | 開発サーバー起動（http://localhost:5173）               |
| `pnpm test`                 | 全パッケージのテスト                                    |
| `pnpm build`                | 型チェック + クライアントのビルド（`apps/client/dist`） |
| `pnpm lint` / `pnpm format` | ESLint / Prettier                                       |

`http://localhost:5173/?seed=42` のように `seed` を付けると、そのシードで新しいランを始めます。

## ディレクトリ構成

```
packages/
  sim/            純粋なシミュレーション・ラン進行・バランス定数（外部依存ゼロ）
    src/
      balance.ts        ★ ゲームの数値はすべてここ（価格・倍率・発動回数・ノルマ・予算）
      types.ts          盤面・信号・イベントなどの型
      core/             スコア型・シード付き乱数・方向・盤面ヘルパー
      simulate/         simulate() 本体と、パーツ1種=1ファイルの挙動定義（parts/）
      run/              ラン進行（シフト・購入・配置・撤去・ショップ生成・ノルマ判定）
    test/               決定論・停止性・各パーツ・連鎖スナップショット・通しプレイ
  shared/         client / server 共通の型（セーブデータ形式とバージョン管理）
apps/
  client/         Web版クライアント（Vite + PixiJS + React）
    src/
      board/            PixiJS の盤面描画と演出再生
      playback/         イベント再生のタイミング制御（描画に依存しない）
      state/            画面状態の reducer・セーブ/ロード
      ui/               React の各パネル（HUD・ショップ・手持ち・結果画面など）
      i18n/             文言（ja.json / en.json）
      assets/manifest.ts 見た目の定義（仮素材 = 色付き図形 + 頭文字）
legacy/machigai/  以前このリポジトリにあった別ゲーム（まちがい仕掛け人）
```

## 遊び方（フェーズ1）

1. ショップでパーツを買う（買ったパーツは手持ちに入り、そのまま配置待ちになる）
2. 盤面の空きマスをクリックして配置。`R` キーで向きを回転
3. 盤面のパーツをクリックすると回転・撤去（半額返金）ができる
4. 「試運転」は何度でも可能。「スイッチを押す（本番）」でシフトの結果が確定
5. ノルマ達成で次のシフトへ（盤面・手持ち・残予算は持ち越し）。3シフト達成でクリア
